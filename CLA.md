# Audastra 贡献者协议（CLA）

版本 1.0。英文为正式文本，中文为说明；两者不一致时以英文为准。

## 为什么需要它

Audastra 编辑器以 PolyForm Noncommercial 公开源码，同时由作者 CallDisaster 另行提供商业授权；共享渲染核心以 GPLv3 公开并附加许可。为了让作者能继续用这几种方式授权整个项目（包括你贡献的部分），合并 Pull Request 前需要你签署本协议。**你的贡献版权仍归你所有**，本协议只是授予作者使用和再授权的权利。

签署方式：在 PR 下按机器人提示回复约定的英文语句。只需签一次，之后的 PR 自动生效。

## 要点（说明，非正式文本）

- 你保留贡献的版权，可以在别处随意使用自己的贡献。
- 你授予作者永久、全球、免费、不可撤销的许可：可以使用、修改、分发你的贡献，并以任何条款再授权（包括项目现有协议和商业授权）。
- 如果贡献涉及你拥有的专利，你同时授予相应的专利许可。
- 你确认贡献是你自己写的，或你有权这样提交；如果包含他人的代码，需要标明来源和许可证，且不得来自许可证不兼容的项目。
- 你的贡献按“现状”提供，你不承担担保责任。
