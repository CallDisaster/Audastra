# 世界完成帧基线

此入口记录世界页的实际完成帧，用于反馈世界页卡顿或动画停住的问题。
整个编辑器、CLI 和 MCP 仍可从本包正常启动。

1. 双击包内 `tools\Measure-World.cmd`，输入地图路径和含 `war3.mpq` 的游戏资源目录。
   脚本自动复制地图到新测量目录。原图只读，编辑器打开副本；需要旧 UI 时可用下面的参数入口。
2. 等世界模型加载，定位到有应播放动画的单位或粒子的区域。确认“本视区有应播放动画的单位或粒子”及“窗口可见且未被遮挡”，再点击“开始记录”。即使这些对象的画面已经停住，也应勾选第一项；测量会分别记录应当播放、实际姿势变化和截图停滞。
3. 连续操作至少十分钟，尽量覆盖固定区域、密集区域、纯地面、平移缩放、暂停恢复及切页返回。
   若切换应用或窗口被遮挡，取消可见复选框。暂停播放有单独记录；不需要手动截屏。
4. 点击“停止并导出”。保留 `measurements/日期-编号/` 整个目录给开发者，不只给汇总数字。
   关闭窗口会结束当前记录；已写的 JSONL 和截图仍保留。

带参数启动（中文和空格路径须保留引号）：

```powershell
.\Measure-World.ps1 -Map "C:\地图\测试.w3x" -GameRoot "D:\Warcraft III" -UiRoot "D:\YDWE"
```

直接程序入口为 `bin/war3-map-editor.exe --open-map <副本> --game-root <资源根> --measure-world <尚不存在的记录目录>`。
可见测量不需要 `--exit-after-open` 或 `--probe-world`。

导出包括每个实际完成帧的日志、CPU 动画尝试及拒绝、截图记录和 PNG 序列、实际设备与视口尺寸、相机和各阶段耗时分布。
地图编辑修订、地形视口修订、姿势版本及完成帧号分别记录。
截图默认每 2.3 秒读取，读回与 PNG 编码耗时单列。CPU Draw/Present 不能当作 GPU 时间；当前 GPU 时间不可用。

有效动画帧率仅在作者确认可见、活动对象投影在本视区、对应完成帧的姿势或粒子数据确实变化时统计。
见证对象不明确、暂停、最小化、遮挡、旧插件、过期帧和丢失记录均不能产生通过结论。
后台诊断仍明确标成后台，不能用来签收作者实窗问题。

作者已经接受 Round4-A1 的实测作为 A2 基线。本包不要求重新做三分钟基线；需要同图连续十分钟、有效动画完成帧率至少 20 FPS 的日志和截图。放置延迟属于后续 A3，仍独立验收。
