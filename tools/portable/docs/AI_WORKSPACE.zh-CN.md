# 内置 AI 与当前地图 MCP

这一版保留完整桌面编辑器，提供原生 AI 工作区、提供商与模型设置、本机 HTTP MCP，以及自然语言 T 的共用工具桥。运行时随包提供，无需另装 Node 或 npm。首次启动不会自动连接模型，也不会自动开放 MCP。

## 开始使用

1. 用包根目录的 `Audastra.exe` 打开编辑器，配置已有游戏资源和 YDWE 来源，打开地图副本。
2. 从设置菜单打开“应用设置”，启用内置 AI。在“提供商与模型”添加名称、网站和 API 地址，选择站点实际支持的协议，输入 API 密钥。
3. 点击“获取模型”，勾选准备使用的模型。目录接口不可用时可以手工填写模型 ID；列出的模型仍需要站点授予调用权限。
4. 点击模型可填写上下文 tokens。留空依次采用提供商声明、已知模型默认值；都没有时显示 256K 估算。这个估算不等于站点承诺的窗口。
5. 保存设置，从顶栏“助手”或 `Ctrl+Shift+A` 打开 AI 工作区，选择提供商与模型，输入任务。`Ctrl+Enter` 发送。

先只开放查询。需要修改时在“Agent 权限”启用编辑；需要写地图时再启用保存。两者独立控制。运行中可以停止；已经完成的编辑不会因停止而丢失，可通过原编辑器撤销栈撤销。

密钥使用当前 Windows 用户的 DPAPI 加密保存，普通设置仅存凭据引用。包内不包含密钥。把程序复制到另一台电脑后，应在该电脑重新配置凭据。

## 能看到的内容

助手默认占用应用中央视窗，顶栏继续保留。可以从助手内切换为右侧栏或独立窗口，三个模式保持同一份输入、对话、工具详情和任务。侧栏目标宽度为 420 逻辑像素；主窗口至少 1280 宽且有足够空间保留原编辑区时才显示侧栏，否则自动改为完整页。独立窗口可单独缩窄。返回编辑器或关闭独立窗口只隐藏助手，不取消在途任务，停止由明确按钮执行。

对话、工具活动和改动在同一阅读流中。助手说明直接显示，用户消息右对齐，工具调用默认折叠为薄行；展开可查看实际参数、结果、耗时和失败原因，真实改动包含前后值及对象跳转。底部输入区随文字增长，提供商与模型控件放在输入区内。新增行、删除行、T 节点与文件计数分别显示；T 的结构修改不会冒充代码行数。数字按真实工具结果递增，“减少动画”可直接显示最终值。

会话历史保存在本机，按地图、提供商和模型绑定。切地图不会带入另一张地图的历史。标题旁的加号开始新会话，旧审计仍保留。模型未报告 token 用量时显示未提供，不伪造价格或用量。

## 当前 GUI 工具范围

| 工具 | 作用 |
|---|---|
| `editor_state` | 当前 GUI 工程身份、修订及可用能力 |
| `editor_query_trigger_graph` | 有界查询当前自然语言 T、分类、变量、节点及图绑定 |
| `editor_get_ui_catalog` | 查询当前生效的事件、条件、动作和函数签名 |
| `editor_edit_trigger_graph` | 验证整批图编辑并加入 GUI 共用撤销栈 |
| `editor_save_map` | 通过原地图保存链保存或另存，返回实际文件 SHA |

这一批工具直接操作当前 GUI 文档。编辑前查询最新身份和绑定；保存后重新查询。来源或修订变化会拒绝旧请求，不猜对象 ID。

默认新增逻辑保持作者可编辑的自然语言 T。已有自定义代码保持原样；只有作者特别要求才写 JASS、Lua 或 WCT。Lua 编译目标是保存产物，不改变默认的 T 编辑方式。

这一版 GUI 工具桥尚未开放任意文件写入、通用 shell、物编和地形编辑。原独立 stdio MCP 的其他工具属于它自己的工作区，不会自动同步到当前 GUI。

## 外部 Agent 接入

在“应用设置 → MCP 连接”启用服务并设置端口，保存后查看实际监听结果。只监听本机回环地址。再次打开设置可复制访问令牌及连接说明；令牌不要发进聊天或提交到 Git。

把设置页显示的实际 HTTP 地址和 Bearer 令牌填入客户端。地址形式是 `http://127.0.0.1:8767/mcp`，端口以实际设置为准。客户端配置格式因产品而异。本服务提供 JSON 响应的 Streamable HTTP；不提供 SSE 或工具列表变化推送，改变权限后客户端需刷新工具目录。

可按组和单项关闭工具。关闭后既从目录移除，也在调用前拒绝，客户端的旧缓存不能绕过。HTTP 请求与内置 AI 共用同一工具代理和写事务。

通过 `resources/list` 可发现版本化的 Skill 清单、正文及参考资料；读取这些资源，或直接读取随包 `bin/skills/`。资源可发现不等于客户端一定会自动加载 Skill：执行高频事件优化前应明确读取 `forge-t-event-optimization`。该 Skill 要求实际迁移业务到单位类型登记、实例订阅、中央分发和清理，不能只造管理器或改名称。

## 保存与验收

正常保存写回当前打开地图，写前自动备份并保留最近十份；另存到指定新路径。Agent 自己验收时使用独立副本，保存后重开回读。没有可用编译器、来源变化或脚本检查失败时拒绝写出，保留诊断。

本轮后台回归使用原创地图与本机协议夹具，不使用作者密钥。真实站点的模型权限、工具能力、作者前台观感和 Warcraft 游戏行为仍需分别确认。
