# Audastra 试用版（Windows x64）

Audastra 是一个新写的魔兽争霸 III 地图编辑器，面向经典版 / YDWE 地图。这是给作者们试用的早期版本，欢迎多挑毛病。

## 先读这三条

1. **请用地图副本试。** 点“保存”会写回当前打开的地图。写前自动备份，默认保留最近 10 份；目录和数量可在“地图测试与备份”中设置。
2. **保存出来的地图请自己进游戏、用原版编辑器再确认一遍。** 我们还没完成“原版编辑器打开 + 实际进游戏”的完整验收。
3. 包里不含游戏或地图，需要你本机已有。扩展触发器定义和 JAPI 运行时按需要由你提供。

## 启动与首次设置

1. 解压后保持目录结构，双击根目录的 `Audastra.exe`。不需要安装 Qt、VS 或 Node。
2. 右上角“设置”菜单里依次设置：
   - **Warcraft III 安装目录**：选含 `war3.mpq`、`war3x.mpq` 的游戏目录。不设置时没有真实头像和模型。
   - **触发器定义目录**：仅使用 YDWE 扩展触发器时需要，选含 `ui` 的那一层。不设置时这些扩展函数无法显示和编辑。
   - **扩展资源目录**（可选）：一般也选 YDWE 目录，用来补充图标。
3. 打开地图副本，开始试用。
4. “设置 → 应用设置”里可以改界面字体、主题，以及启用 AI 助手。

## 可以试的东西

- **物体编辑器**：七类物体的浏览、字段修改、技能列表选择、复制。
- **触发器**：传统事件/条件/动作树、参数选择、变量表。
- **代码编辑**：自定义 JASS、vJass 和原生 Lua 代码，支持行号、缩进、折叠、问题列表及有来源依据的定义与引用导航。检查在后台进行；语法检查不会运行 Lua。
- **Lua 脚本草稿**：可在工程中保存未完成的脚本并恢复，应用一次进入共同撤销栈。经典地图的扩展 Lua 入口尚待运行时规格确认，当前不会把此类草稿写回地图。
- **最近地图**：启动页、文件菜单和管理窗口共用最近十条地图记录，可固定、移除及清理失效路径；固定条目不会被自动挤出。
- **其他**：声音、资源导入、地图设置、物体管理（引用查找）。
- **测试地图**：工具栏“测试”或 F9，使用独立副本测试当前内容，保留原图、未保存标记与撤销。普通经典地图直接启动所选魔兽，无需 YDWE。扩展 JAPI 配置与可选的 SLK 优化见 [地图测试说明](docs/MAP_TEST.zh-CN.md)。
- **世界视图**：地形和模型显示、点选/框选、单位移动/旋转/复制。这里是预览近似，画面不保证和游戏完全一致。
- **AI 助手**（可选，顶栏“助手”或 Ctrl+Shift+A）：需要你自己的模型 API 密钥。
  - 在“应用设置”里添加提供商并启用模型。
  - 密钥加密保存在你本机，不会写进地图。
  - 助手改的内容会进撤销栈，可以随时撤回。

## 目前还不行 / 已知问题

- 蓝图视图、战役、RTS AI、地形笔刷还没做完。
- 旧版 YDWE 的部分地图：缺少配套编译器或不支持的模板时，会拒绝保存并说明原因。这不是程序崩溃。
- 世界视图的粒子、光照是近似效果。少数模型引用了不存在的贴图时，那部分效果不显示。
- 偶尔可能出现助手回复后到下一条提问之间有大段空白。如果遇到，请告诉我们当时做了什么操作。
