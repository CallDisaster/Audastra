# 地形保存的占地贴图格式

地形保存从地图和游戏资源读取实际占地贴图。普通对象先完整查找 TGA，确认不存在后才查找 BLP；地图内的 BLP 不会抢在游戏中的 TGA 前面。缺失、损坏或来源不能确定的贴图会阻止保存。

| 对象占地 | 支持的 TGA 图像类型 | 宽高 |
| --- | --- | --- |
| 普通装饰物、可破坏物及可行走对象 | type2 未压缩真彩色、type10 RLE 真彩色 | 分别为 1..256 像素，可为矩形 |
| 特殊地形装饰物 | type2 未压缩真彩色、type10 RLE 真彩色 | 继续按特殊地形的占地尺寸规则检查 |

两种类型均只接受 24 位 RGB 或 32 位 RGBA，无 ID、无色表、XY 原点坐标为零、
左侧原点且无交错。24 位的属性位数须为零，32 位须为八；顶部和底部原点均受支持。
RLE 原样包和重复包均可跨行，但必须恰好展开成完整图像，不能少像素或多像素。

像素后可以没有附加区，或带两个 offset 均为零、签名为 `TRUEVISION-XFILE.` 加终止零字节的
标准 26 字节 footer。非零 ID、色表、右侧原点、其它位深、交错、非零附加区 offset
及未知尾随字节暂不支持。

贴图红、绿、蓝通道的非零值决定占地属性；alpha 不清除这些属性，但参与完整像素是否
同色的判断。24 位贴图按 alpha255 解释。对象旋转、固定角度、类别吸附和地图边界仍会
进一步限制占地是否能唯一重建；支持某种 TGA 格式不代表该对象已满足全部保存条件。

RLE 解包也计入本次保存的资源预算。超过预算时保存会被拒绝；重新编码为相同像素也会
改变贴图的来源身份，需要重新准备保存。

特殊地形的通行、水面编辑形状和阴影接收面共用相同的 TGA 解码规则，保留原来的
alpha 层级与上下原点。特殊地形仍按 RGB 通道等于 255 判断属性，并继续检查完整
占地尺寸、地形层级和摆放顺序；RLE 支持不会取消这些条件。

普通对象的 BLP 回退支持 BLP1 调色板和 JPEG 图像，宽高分别为 1..256，
只使用完整的 mip0。调色板 alpha 支持 0、1、4、8 位。BLP2 暂不支持。
解码与 JPEG 工作缓冲在分配前计入同次捕获预算；RGB 决定通行贡献，透明像素仍参与。
回退不适用于特殊地形模型，也不适用于已存在但损坏或尚不支持的 TGA。
保存会同时核对首选 TGA 的缺失身份、实际 BLP 的字节和生效来源；其间新出现 TGA
或替换任一实际输入时，必须重新准备保存。
