# 自定义代码转回触发器

在触发器的代码视图选择“转回 T”，可以把能辨认的 JASS 生成写法重新变为事件、条件、动作。转换之前会使用保存地图时的同一生成器重新生成候选，逐词比较通过才允许确认。不能辨认的函数、控制流或不一致之处会指出行号，原代码保留。

YDWE 的延后注册、局部循环、计时器与触发器闭包、范围遍历，以及函数或条件参数可以按其生成形状辨认。对于局部变量和自定义值的哈希表展开，代码中的整数键无法还原为原来的名字；可确认的读写会恢复为原生哈希表动作，必须保持原文的表达式会显示为自定义代码。确认框会列出保留的代码行、表达式数量。这类部分恢复与完全恢复为结构化 T 分开统计。

把 T 转为自定义代码时，编辑器会记录转换前的完整结构，包括禁用动作。保存 `.forge` 工程会连同快照保存；重新打开工程后，代码正文和所属触发器仍与快照一致时，可以原样转回。正文改动后会重新走解析。只保存游戏地图不会携带编辑器快照，重新直接打开地图也不会读取其他工程的快照。

快照与工程来源、触发器顺序、函数库及正文绑定。损坏、未知版本或与工程内容不相符的快照会阻止该工程载入，当前打开的工程保持不变。转码、转回均使用同一撤销历史；撤销或重做转码会同时恢复对应版本的快照，转回后撤销仍可再次使用保存的快照。同一会话中先保存地图、再保存 `.forge`，快照仍会随工程保存。

重新生成一致证明的是编辑器内的代码往返。涉及 YDWE 扩展功能的地图仍需要作者在原版编辑器打开副本，并用经典版游戏测试相关触发器。
