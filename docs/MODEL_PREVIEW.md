# 模型预览与诊断

世界页选中单位后，右侧模型卡可选择动作、播放/暂停和单步。切换动作从第 0 毫秒开始；不循环动作播放结束后，再点“播放”会重新开始。模型卡、世界视图、摆放预览与模型缩略图共用交互预览规则。保存和严格回放的检查不随预览放宽。

交互预览按经典版游戏已确认的文件顺序读取动作轨迹。局部错误或未支持内容仍保留诊断；“预览近似”不代表已经在原版编辑器或游戏里确认。ModelSpace 粒子跟随当前发射节点，普通粒子留在发射后的世界轨迹；XYQuad 使用粒子速度的 XY 投影定向，零 XY 速度可以形成退化面。

开发工具 `war3-mdx-scan` 在 Windows 上支持宿主预览诊断。用临时目录中的地图副本扫描导入模型，并用用户本机游戏安装补齐原版资源：

```powershell
& $scanner --preview 1 --map $mapCopy --game-root $env:FORGE_WORLD_GAME_ROOT --tsv $newReport
```

去掉 `--map` 可扫描游戏包中可枚举的模型；`--list` 可显式指定 UTF-8 模型清单。没有地图或游戏来源时，清单中是磁盘路径，相对路径相对清单目录。内部资源只读取同目录下的安全相对路径。报告路径必须不存在。

每个模型在独立受限子进程中按动作起点、中点和终点采样。`--model-ms`、`--total-seconds`、`--memory-mib`、`--max-models`、`--max-samples` 等限制通过 `--help` 查询。工具不会截断预算后报完整覆盖。

输出包括主表、`.diagnostics.tsv` 逐模型诊断、`.categories.tsv` 分类计数与代表模型，以及 `.scope.txt` 来源与覆盖说明。`strict` 与 `interactive` 是**同一版本的两种策略**，不是修复前后两个版本。`complete` 只表示声明的样本已检查，模型仍可能存在诊断；`visible` 是有可提交几何的样本数，不是截图或 GPU 验收。归类为 `rejected_data` 的条目表示当前读取器拒绝，不能据此断言原版游戏也无法使用。

MPQ 名单只覆盖可读 `(listfile)` 中的名称，不会把未知成员声称为已扫描。地图中的 `war3map.w3e` 用于确定地形集，让嵌套资源包顺序与世界页一致；地形读取或解析失败时会停止该来源的扫描，记录为来源上下文受限，不据此判断模型损坏。预算未覆盖、来源失效、缺失资源、未支持功能和未知诊断分别保留。扫描只读取源文件，不执行地图代码，不启动游戏，不替代原版编辑器、游戏或作者目测。
