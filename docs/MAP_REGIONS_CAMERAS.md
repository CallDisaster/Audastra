# 区域与镜头

在“地图实例”页切换到“区域”或“镜头”，使用“新建”和“删除选中”。双击属性可以修改；所有操作进入该页的撤销栈，保存工程会保留编辑覆盖，保存地图会写出原生 W3R/W3C 并重新生成初始化脚本。

也可以在“世界”页的场景目录使用“新建 → 新建区域 / 新建镜头”。选中区域或镜头后，“属性”或右侧“完整属性”可编辑完整记录；“副本”和“删除”使用相同的引用检查与撤销。属性窗口打开后，地图或所选对象发生变化时会拒绝旧草稿，请重新打开属性。新建的初值可以在窗口中调整。

区域可以修改名称、边界、天气、环境音和颜色。天气填写四字节 rawcode，留空表示无天气。环境音填写“声音”页已有的声音变量，例如 `gg_snd_Ambient`；不能填写文件路径或音乐变量。保存脚本会把声音放到区域中心，并使用区域宽高注册环境音。颜色按 B、G、R 顺序填写六位十六进制；原文件的第四个颜色字节保留。

原有环境音、天气或声音标志无法解释时，编辑其它属性仍保留这些原值。重新生成整图初始化脚本时，如果无法证明这些值的用途，保存会报出原因，不会把它们改成默认值。

镜头可以修改名称、目标位置、高度偏移、旋转、攻角、距离、滚转、视野和远裁剪。角度使用度数。经典 W3C 的第十个数值槽保持只读，编辑不会把它当成已经确认的近裁剪接口。

世界页可以拖动区域的边角和镜头目标；镜头视锥仍是编辑辅助近似，不表示已验证原版游戏的完整投影。

新增记录需要完整且已确认的经典成员布局。缺少 W3R/W3C 时，只有地图设置明确属于经典格式才创建成员；损坏、重复来源或扩展布局会保留并显示具体原因。

删除或更名之前会检查触发器参数、变量初值和传送门目标。已有引用需先修改；自定义代码、外部脚本或未完整读取的触发器无法证明没有引用时，会拒绝删除或更名并说明覆盖缺口。移动边界、目标位置及其它属性不需要更改脚本变量名，可以继续编辑。

MCP 的 `entities_query` 返回原成员 SHA 和行身份；区域、镜头结构操作使用 `auxiliary_create`、`auxiliary_update`、`auxiliary_copy`、`auxiliary_delete`。每次带上 `project_identity`、`expected_revision`、`kind`（`regions` 或 `cameras`）及 `expected_member_sha256`；已确认成员缺席时填 `missing`。更新、复制和删除还需 `source.source_index`（十进制字符串）及 `source.row_key`。这些身份只适用于查询时的同一修订；命令返回后应使用返回的新修订和结果行身份，或重新查询。

`auxiliary_create` 的 `fields` 必须包含完整已知属性。区域为 `name`、`creation_number`、`left`、`bottom`、`right`、`top`、`weather_id`、`ambient_sound` 和三个整数的 `color_bgr`（B、G、R）。镜头为 `name`、`target_x`、`target_y`、`z_offset`、`rotation`、`angle_of_attack`、`target_distance`、`roll`、`field_of_view`、`far_clipping_plane`，角度单位是度。`auxiliary_update` 只提供需要改变的字段，未提供的原生名称、浮点位模式、区域第四颜色字节和镜头第十槽保持原值。`auxiliary_copy` 先完整复制原记录，再应用 `fields`；必须明确提供新 `name`，复制区域还必须提供新 `creation_number`。创建编号重复、名称对应的脚本符号重复、已有引用和引用覆盖不足都沿界面的同一服务检查。

`dry_run: true` 只返回候选身份，不推撤销命令。实际命令返回 `result_identity`，进入原宿主撤销/事务链；没有字节变化时不产生新命令。活动编辑器中的外部 MCP 和内置助手使用同一组结构工具，直接编辑当前地图并进入界面的地图数据撤销栈；预览不提交界面草稿，实际命令在提交草稿后复核工程、修订和来源。工具回执不表示地图已经保存。

独立 MCP 在 `begin_edit` 事务内最多累计 128 条区域/镜头命令，可以连续编辑新建或复制后的行并同时修改两类成员；`rollback` 放弃活动事务。先 `preview_edit`、`validate_edit`，再用 `export_map_candidate` 写独立目录候选，或用带实际源地图 SHA 的 `save_map_edit_candidate` 走完整脚本与地图保存链。保存从实际归档来源重放同一命令序列，复核触发器/脚本引用、W3I 布局、声音和传送门来源，并核对输出及回读成员。独立区域/镜头结构事务暂不混入字段、预放、地形、触发器或物编归档变化；应分别导出并重新打开候选。

原 `entities_set_fields` 仍可在独立字段事务中修改区域边界、`weather_id`、`color_bgra` 和镜头已知数值。`color_bgra` 的最高字节必须保持原值，`near_z` 只读。结构命令沿用相同原生布局、引用、来源变化和保存门禁；候选文件写出、原版编辑器保存和游戏运行是分别验证的步骤。

世界页用圆环和十字显示地图中已有的起始位置。选择后拖动，或在属性里修改 X、Y，会在一次可撤销操作中同步对应玩家的起点；Z 沿现有移动规则保持与地表的相对高度。起始位置不是普通模型，不能直接复制、删除或改变所属玩家。对应玩家缺失或一个玩家有多个起始位置时，移动会说明原因并拒绝整组修改。隐藏、锁定和当前渲染插件的能力也会影响标记显示与拖动。
