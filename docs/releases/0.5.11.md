# Audastra 0.5.11

这一版是补丁版：世界页更流畅，几处显示和游戏不一致的地方改对了，并修复大地图上改触发器、装饰物后不能撤销或保存的问题。

## 世界页

- 更流畅：
  - 动画放到多个核心上计算，每帧只上传有变化的部分，按显示器刷新率出帧。
  - 长时间开着世界页，内存不再一直上涨。
  - 在一台入门级专业显卡的测试机上，大地图固定视角约 60 帧，边转镜头边编辑约 57 帧。
- 可以选择世界页用哪块显卡渲染：设置的“世界特效”页里选“显卡”。
  - 默认“跟随系统”。
  - 选中的显卡不在这台电脑上时，自动退回系统默认显卡，世界页状态栏会注明。
- 修复：单面材质的背面现在不画，和游戏一致。平放在地上的模型（书架、箱子一类）不再露出底面，也不再和地面互相遮挡成大块黑色。
- 修复：装饰物先按朝向旋转、再沿世界坐标轴缩放，和游戏一致。地毯一类非等比缩放的装饰物，转向后不再往错误的方向拉伸。
- 修复：地形最底层的贴图也按透明度混合，和游戏一致。把地形贴图换成透明贴图的地图，那块地面现在透出下面的内容，而不是显示一块不透明的地面。
- 场景里的模型超出显示预算时：
  - 只跳过放不下的模型，其余照常显示。以前整个世界页的动画显示会失败。
  - 跳过的模型按地图里的存放顺序决定，列在“模型诊断”里。
  - 场景能容纳的模型比以前多：顶点上限约为原来的 1.8 倍，索引上限为原来的 2 倍。
  - 同一块显存缓冲最多用到 128 MB，显存小的显卡（例如核显）不会因为缓冲太大而上传失败。

## 物体编辑器

- 修复：自定义物体从“未经地图修改的”标准物体继承数据，和游戏一致。例如地图只给某个标准装饰物改了颜色，以它为基础的自定义装饰物不再跟着变色。

## 地形与摆放

- 新增：导入外部高度场（世界页地形面板的“导入高度场…”）。
  - 整张图的高度一次导入，可以一步撤销。
  - 新建地图上还没刷过材质的平地，也可以导入到任意层级。
- 新增：导入摆放清单（世界页“新建”菜单里的“导入摆放清单…”）。
  - 一次带入外部模型，为它们新建自定义装饰物或单位类型，并摆放全部实例。
  - 几千个新类型一次批量创建，不再要先等几分钟。
- 修复：装饰物很多的大地图（装饰物文件有几 MB），改动装饰物、导入摆放清单或替换导入文件后，保存不再报“预算不足”。
- 修复：地图改过某个原版物体、又以它为基础做了自定义物体时，改动装饰物后的保存不再一律被拒绝：
  - 自定义装饰物按游戏的规则取值：原版数据加上自己的修改，不继承地图对原版物体的修改。
  - 自定义可破坏物：原版物体被改过的字段，自定义物体自己也改了，就不再拒绝。
- 命令行 `map-edit-save` 新增 `--terrain-heightfield` 和 `--placements`，和编辑器里的导入走同一套检查。

## 撤销

- 世界、地图设置、声音各有一份自己的撤销记录。在一个页面里撤销，不会撤掉另一个页面的修改。
- 修复：触发器动作特别多的地图（十几万个动作节点），改触发器后没法撤销，还会误报“来源已改变”。

## 触发器

- 局部变量的“类型冲突”提醒只在实际存储类型不同时出现。实数、角度、弧度都按实数存；字符串、模型文件、图像文件都按字符串存，混用这些类型不再提醒。

## 保存

- 保存打不开来源地图时，写明真实原因（文件不存在、被其他程序占用、没有权限）和文件路径。以前文件不存在也会报成“正在被其他程序写入”。
- 预算不够时，写明是哪个文件、多大、需要多少、还剩多少。
- 命令行保存时，相对路径在一开始就转成完整路径，不会到生成小地图那一步才失败。

## 助手与 Agent 工具

- `map_test_capture` 可以连拍 2–16 帧，并指定间隔，用来看飞行中的投射物和正在播放的特效。
- 游戏截图没有返回时，同一次测试里后面的截图直接改用窗口截图，不再每次都等 4 秒超时；回复里会说明为什么跳过了前面的方式。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 游戏会在单位周围取几个点决定高度，编辑器只取单位中心一点；坡地边缘和岸边的单位可能和游戏里略有高低差。
- 两栖单位按所在位置的水深决定浮在水面还是走在水底，不模拟单位当时的游泳状态。
- 特效特别多的视野里，世界页帧率会下降；编辑器会自动减少同时模拟的特效数量，被省略的数量显示在状态栏的“预算省略”里。
- 关联了外部 Lua 文件夹时，`lua_files_delete` 直接删除磁盘上的文件，不能在编辑器里撤销。
- 世界页打开后，模型仍是全部读完才一起显示，还不能先显示镜头附近的模型。
- 界面编辑器新建界面仍需一秒多，后续版本继续优化。
- 外部 MCP 服务器：
  - 每个服务器只能保存一条密钥；HTTP 方式只支持 Authorization 请求头。
  - `npx` 这类命令要写成 `cmd` 加参数 `/c npx …` 才能启动。
  - 设置里格式不对的 MCP 条目在加载时会被跳过，再保存一次设置后就不在了。
- 界面编辑器里游戏自带的原版样式还没在游戏里逐个核对，暂不在创建卡片里列出。
- 删除物体时，按变量或函数取值的触发器参数、地图导入的脚本无法静态检查，需要你自己确认没有用到。
- 少数模型预览仍显示不出来，原因见 0.5.2 说明。
- 地图把可行走的可破坏物（桥一类）的通行贴图清空后，改动装饰物的保存仍会被拒绝，提示里写明是哪个物体。游戏对这种情况的处理还没查清，编辑器不猜。
