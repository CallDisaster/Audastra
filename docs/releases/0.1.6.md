# Audastra 0.1.6

本次更新以经典版地图的资源读取、世界预览、保存保护和助手文件工具为主。

## 世界与资源

- 修复部分地形贴图、TGA 模型贴图和自定义装饰物的资源读取。缺少带编号的装饰物变体、但存在无编号模型时，按实际资源来源选择可用模型。
- 修复水面第一层纹理完整、后续 mip 损坏时整帧不可用的问题。损坏的第一层和超过预算的输入仍明确拒绝。
- 修复模型材质的“不受雾影响”标志未传入渲染器的问题，静态和蒙皮材质均使用同一语义。
- 按经典版读取行为兼容部分 PREM 哨兵节点编号与空法线模型。保留原始字段和诊断；缺法线的静态外观使用预览法线，不能据此认定动画或原版外观完全一致。
- 自动探针在世界页不可见时也能真实加载和出图；完成帧记录地图来源、修订和相机，资源问题进入诊断列表。

## 编辑与保存

- 区域、镜头和开始位置使用公共编辑命令，支持撤销、保存检查及 MCP 操作。保存时保护已编辑的区域和镜头，避免模板展开覆盖。
- 地形保存计划按明确名字核对地形、通行、阴影和小地图成员，包括未列在地图文件清单中的成员，保存后再次核对字节身份。
- 地形真保存仍只开放干地小幅高度、荒芜等有限操作，并有编辑器内保存回读检查；通用通行、阴影和小地图自动重建尚未完成。不能安全写回的操作继续保留工程草稿并给出原因。

## 代码与助手

- Lua 代码块增加补全、参数提示和悬停；JASS 参数提示与关键字补全继续完善。
- 助手可以列出、读取和修改地图 Lua 文件，并通过共用入口启动地图测试。替换已有 Lua 文件必须携带读取时的版本，防止覆盖之后发生的改动。
- Lua 文件列表支持稳定分页，来源变化或结果过大时明确拒绝，便于助手继续有界查询。
- YDWE 文本参数可以选择返回字符串的函数和变量。

## 更新与反馈

- 更新检查阶段提前提示安装目录混用或安装基线不完整。
- Bug 反馈 QQ 群：**1127618143**。

## 已知限制

- 部分缺失导入资源、损坏或不支持的模型仍无法正常预览，并会显示诊断；不使用猜测资源替代。
- 世界预览与 Warcraft III 1.27a 的完整光照、阴影、粒子和雾效果仍有差异。
- 通用地形派生重建、原版编辑器真保存重开和游戏内兼容需要继续验证。本次不把地图可读取、编辑器内往返或截图成功当作这些验证已经完成。
- 重制版地图尚未支持。请继续在地图副本上试用。
