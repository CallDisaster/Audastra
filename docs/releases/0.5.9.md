# Audastra 0.5.9

这一版是补丁版：修复大型地图在世界页不显示模型、不显示单位的两个问题，世界页能同时显示更多粒子特效，AI 助手和 MCP 增加批量删除。

## 世界页

- 修复：模型和贴图很多的大型地图，世界页一个模型都不显示。
  - 原因：全部模型贴图共用 160 MiB 的预算，用满以后整个模型场景被判为失败。
  - 现在的上限：模型贴图总量 2 GiB，模型文件总量 2 GiB，模型种类 16384。
  - 即使真的超出上限，也只是超出的那部分贴图不显示，其余模型照常显示。
- 修复：地图里有某个方向缩放极小的摆放（比如压扁到 0.01 或缩到接近 0 的装饰物）时，镜头从较远处看到它，世界页就整体退回静态显示，模型状态写“动画未启用”，单位不显示、不能播放。
  - 原因：这类摆放会把镜头位置换算到一个超出范围的数值，原来被当成整个场景的失败。
  - 现在只影响这一个摆放：能照常显示的照常显示，实在算不出来的只隐藏它自己。
- 粒子特效：
  - 视野内全部特效共用的粒子总量提高到原来的 8 倍，单帧粒子顶点提高到 3 倍。特效多的地图上，以前大部分特效会被“预算省略”。
  - 刚打开世界页、还没开始播放时的第一帧，以前最多只显示六百多组特效；现在和播放时用同一份预算。
  - 粒子贴图超过 256 张或超出粒子贴图预算时，只省略放不下的那几组特效，不再让全部模型消失。
  - 同时模拟多少特效仍会按帧耗时自动调整。

## AI 助手与 MCP

- 批量删除，内置助手和外部 Agent 都可用：
  - 触发器图查询新增 `batch_remove_audit` 表：一次审计最多 512 个触发器或变量、128 个分类。同一批里互相引用的不算“仍被引用”。
  - `triggers_batch_delete`、`variables_batch_delete`：按审计结果整批删除，只占一个撤销步骤。批外还有引用或证据不全时整批拒绝；可以先用 `dry_run` 预检。
  - `lua_files_delete`：一次最多删 256 个 Lua 文件，删前检查路径提及和 `require`。
  - `imports_remove` 一次最多删 512 个导入文件（原来是 32 个）。
- 删除审计改为整批只扫描一遍代码，大地图上清理一整个功能不再需要逐个触发器等待。

## 其他

- 导入的 .tga 图标现在能正常显示（以前只支持 .blp）。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 特效特别多的视野里，世界页帧率会下降；编辑器会自动减少同时模拟的特效数量，被省略的数量显示在状态栏的“预算省略”里。
- 关联了外部 Lua 文件夹时，`lua_files_delete` 直接删除磁盘上的文件，不能在编辑器里撤销。
- 世界页打开后，模型仍是全部读完才一起显示，还不能先显示镜头附近的模型。
- 界面编辑器新建界面仍需一秒多，后续版本继续优化。
- 外部 MCP 服务器：
  - 每个服务器只能保存一条密钥；HTTP 方式只支持 Authorization 请求头。
  - `npx` 这类命令要写成 `cmd` 加参数 `/c npx …` 才能启动。
  - 设置里格式不对的 MCP 条目在加载时会被跳过，再保存一次设置后就不在了。
- 界面编辑器里游戏自带的原版样式还没在游戏里逐个核对，暂不在创建卡片里列出。
- 删除物体时，按变量或函数取值的触发器参数、地图导入的脚本无法静态检查，需要你自己确认没有用到。
- 少数模型预览仍显示不出来，原因见 0.5.2 说明。
