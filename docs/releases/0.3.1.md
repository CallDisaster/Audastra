# Audastra 0.3.1

紧急修复：地图里有编辑器认不出的坡道写法时，保存被小地图挡住、整张地图存不了。另外加了“无视风险继续保存”。

## 修复

- 保存时报“地图未保存：CLASSIC_MINIMAP_RAMP_UNRESOLVED · S 形坡道未满足原版 L/H/R 邻域规则”的地图现在能正常保存：小地图保留地图里原来的那张，其它修改照常写入，问题列表里留一条警告。

## 新增

- **小地图问题可以无视继续保存**：保存时如果只是小地图无法按当前内容重新生成，会弹出“小地图无法生成”，选“仍然保存”后其它修改照常写入，小地图保留原图（原图没有小地图就不写），游戏里的小地图可能显示修改前的样子。选“取消”则什么都不写。地图来源读不到、文件被外部改动等问题不提供这个选项，仍然拒绝保存。
- Agent 通过 MCP 保存时遇到同样情况会收到 `MINIMAP_RISK_SAVE_AVAILABLE`；作者同意后在 `editor_save_map` 里传 `keep_original_minimap: true` 即可继续保存。

## 升级

- 0.3.0 可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 有这类坡道的地图，保存时小地图不会按新地形重新生成。
- 其余限制同 0.3.0。
