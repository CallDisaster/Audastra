# Audastra 0.5.2

集中修复物编选模型时预览显示不出来的问题。用《冰冠之陨》全部 818 个模型逐个检查，结果如下：
- 修复前约四成能预览；
- 现在 799 个能显示；
- 剩下的主要是模型数据本身有错、空模型或贴图缺失。

## 物编

- 模型预览改为“近似”方式。模型里有暂时不支持的部分时，跳过这部分，并在预览下方写明跳过了什么，不再整个模型显示不出来。
- 打开模型就循环播放，切换动作时保持播放状态：
  - 以前很多特效停在第 0 毫秒，什么都看不见；
  - 一次性特效播完后会从头再来。
- 镜头按模型实际看得见的部分取景。以前不少单位和建筑带一块平时隐藏的大面片（如头像背景板），模型被挤成一个点。
- 刀光、拖尾这类条带的材质有多层、会变化或带光照时，以前整条不画。现在按第一层材质画出来，预览下方写明“条带材质按首层近似”。
- 以下几种常见写法现在能正常预览：
  - 几何体动画（GEOA）带有多余的标志位：以前整块网格被藏起来；
  - 骨骼或条带节点带有导出器写的未知标志位：以前整个模型拒绝；
  - 暴雪特效常见的负发射率、爆发关键帧里的负值（表示“不喷”）、负的粒子尾长：以前当成数据错误；
  - 骨骼旋转里长度为零的数据：游戏按“不旋转”处理，预览现在也一样；
  - 全局序列里关键帧顺序倒置：按游戏的顺序查找；
  - 全局透明度动画过了最后一个关键帧：按游戏的做法接回第一个关键帧；
  - 重制版专用的贴图路径（`_hd.w3mod:` 开头），以及解不开的粒子贴图：按缺贴图处理，显示白色或停掉那组粒子。
- 修复第一次打开选择面板时粒子不显示的问题。
- 模型确实显示不出来时，预览里写明具体原因。
- 以上只影响预览；保存和兼容性检查的规则没有放宽。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 少数模型仍显示不出来：
  - 模型数据本身有错，比如引用了不存在的动画序列、顶点的骨骼编号越界；
  - 空模型或马甲模型；
  - 粒子贴图在游戏和地图里都找不到。
- 个别一闪而过或很细的刀光特效，在预览里不容易看清。
