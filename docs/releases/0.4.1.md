# Audastra 0.4.1

修复群里反馈的触发器参数问题：参数框打不了中文，改完参数列表跳回顶部。自带 Lua 测试环境补上了天气效果。

## 修复

- **触发器参数框可以输入中文了。** 以前用拼音等输入法时，参数框里只能打英文。
  - 输入法正在打字时，回车和 Esc 交给输入法，不会误应用参数或关掉参数框。
  - 点参数框外面会收起参数框，点到的地方照常响应，比如直接点开下一个参数。
- **改完参数后列表不再跳回顶部。** 长触发器里改一个参数，包括函数里面嵌套的参数，列表都停在原来的位置，选中的还是原来那条语句，可以接着改下一个。
- 物体选择器、AI 助手的会话改名框也改用同样的窗口，会话改名可以输入中文了。
- 编辑器程序里不再带构建机的目录名。

## 自带 Lua 测试环境

- **天气效果可以用了。** `AddWeatherEffect` 的天气编号按当前地图实际生效的天气表核对：地图里导入了 `TerrainArt/Weather.slk` 就用地图里的，否则用游戏的。
  - 编号在表里：照常创建，开关、删除都和 JASS 一样；
  - 编号不在表里，或者天气表读不到、格式有误：在调用游戏前拒绝，测试信息写明编号和原因。原版遇到无效编号会直接崩溃，现在不会走到那一步。
- 天气效果和漂浮文字一样，开关、删除只能用创建时返回的值，不能用整数代替。
- 仍不支持 DzAPI、EX 系列扩展接口。

## 升级

- 0.3.0、0.3.1、0.4.0 可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。
- 游戏内界面运行库没有变，仍是 0.4.0。0.3.0 运行库照旧随包带上，用 0.3.x 存过界面运行库的地图照常能改、能保存、能测试。

## 已知限制

- 小地图“通行”图层仍不可用：原版编辑器的通行显示配色还没核实，选了会直接提示。
- 0.4.0 里记的“大图上部分水边悬崖壁显示发黑”，这次在同一位置、同一视角复查了两次，显示都正常，没能再出现。如果你遇到，请截图发到群里，并说一下刚才做了什么操作。
- 还没做：小地图图标编辑；地形块复制后旋转或镜像；跨多次保存一直撤销回去。
- 其余限制同 0.4.0。
