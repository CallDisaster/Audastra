# Audastra 0.3.0

本次更新新增“界面”工作区：在编辑器里画游戏界面，一键生成自然 T 触发器，配套的 AudastraUI 函数库让地图在经典 1.27a 里显示和操作这些界面。地形编辑补齐了悬崖、斜坡、水面和地图尺寸，保存时自动重建通行、阴影和小地图。触发器删除前会先查引用。

## 界面工作区（新）

- **原版界面预览**：用本机游戏的真实贴图画出原版界面，位置按 1.27a 游戏规则摆放。地图脚本里创建的框架，以及计时器窗口、多面板、排行榜、对话框，都按游戏规则预览。
- **画自己的界面**：右键按类型新建背景、图标、文字、进度条、按钮、模型；改锚点、颜色、字体、重复排列；贴图和模型用统一的资源选择器。
- **数值、状态、事件**：文字里可以写 `{生命:1}` 这类取值，进度条和显示状态可以绑定数值；状态覆盖贴图、文字、显示；按钮点击、鼠标进入和离开可以接触发器。
- **一键生成自然 T**：生成的是普通的事件/条件/动作触发器，可以直接在触发器编辑器里读和改。
- **编辑器内模拟**：直接运行地图里自己的触发器来模拟界面，实数按游戏精度计算。
- **六个示例系统**：读条、团队框、目标框、伤害/治疗统计、技能栏、天赋树，用“新建界面 → 从文件导入…”连同示例触发器一起导入，导入后照常修改。
- **常用操作不用手写**：颜色用取色器选；文字右键“插入取值”；事件页一键建响应触发器，模拟页一键建计时器触发器，建好后直接跳到触发器编辑器；状态覆盖里的贴图、模型用资源选择器选。取值为空的贴图显示为透明，游戏里和预览一致。

## AudastraUI 函数库（经典 1.27a）

- 函数库随编辑器提供，在函数库对话框里一键装进 YDWE；生成的触发器通过这个库里的动作操作界面。
- 运行库在游戏里直接改框架：数值、宽度、贴图、显示的高频刷新不经过脚本字符串；带数值的文字由运行库按格式写出，只在数值变化时刷新。
- 界面事件用整数通道取回，不再每秒几十次拼请求字符串。
- 团队框：生命/法力数字、头像、增益图标；举着单位目标技能时点队员框会把技能施放给这个队员，不举技能时点框是选中。
- 运行库没装、版本不支持或还没接通时，界面相关的调用什么都不做，地图照常运行。
- 运行库包随便携包一起提供，装好就能正常保存带界面的地图，不用另外下载。
- 保存时如果函数库目录里没有 AudastraUI，会直接说明缺什么、搜了哪些目录，提示到“函数库…”里安装或更新。

## 地形

- 悬崖与斜坡：直坡、转角坡、湿坡、内转角、连续坡带。
- 水面：加水、去水，浅水、深水笔刷。
- 范围：边界笔刷、可玩区域编辑、改地图尺寸。
- 其他编辑：贴图槽、区块复制粘贴、悬崖和地面调色板。
- 保存时自动重建：通行（含装饰物通行图和桥）、地形阴影、小地图标记、出生点；单位摆放和地形改动可以同一次保存。
- 保存后撤销历史仍可恢复。

## 触发器

- **删除前查引用**：删除触发器或变量前，会查其他触发器、自定义代码，以及展开后的 include、宏和模板。确定的引用和可能按名字调用的地方会列在确认框里，作者确认后照常删除。
- 自定义代码触发器可以在触发器目录里改名、复制、粘贴。
- 旧版编辑器写法的触发器引用可以一键改正。
- 写入时检查实数和局部变量的类型。
- 在触发器目录里改名时，自定义代码里没有用到这个触发器的直接改名；可能用到的会先问你，代码本身不会被改动。

## 其他模块

- **变量**：类型、数组、初始值在一个表单里改。
- **地图设置**：随机单位/物品表、科技限制、升级可用性。
- **物编**：分级字段可以按原版公式自动填。
- **声音**：声道和 EAX 效果用原版名字选。
- **物体管理**：可以跳到地图里摆放的实例。
- **装饰物/可破坏物**：显示原版分类图标。
- **备份**：地图换了目录，旧备份会自动迁移过去。
- 帮助文档补上了以上新功能。

## 测试与 Agent

- 测试场景可以直接用自然 T 写。
- 命令行可以把界面描述和示例触发器一起导入地图并正常保存。
- 1.27a 测试可以在不可见窗口里运行，不抢焦点，也能截图；测试中可以向游戏发鼠标和按键，并正常退出游戏。
- 你能在编辑器里实时看到 Agent 对触发器和变量的修改。
- Agent 删除触发器或变量时，必须先拿到引用审计结果并逐项确认。

## 修复

- 编辑器内存只涨不降：整图检查缓存改为共用一份，闲置 3 分钟释放；每次检查约从 15 秒降到 7.5 秒。
- 大地图的触发器查询从约 2.7 秒降到 0.1–0.2 秒。
- MCP：断线导致编辑器崩溃；慢操作断连；保存失败没有原因。
- 短的 GBK 中文被误判成 UTF-8；大地图脚本被保存检查的长度限制误拒。
- JAPI 里 0 和很小的实数编码错误。
- 地形：模型解析失败时小地图被清空；有未完成的编辑时保存或切换出错。
- 声音目录不完整时由报错改为警告；更新时目录被占用的偶发失败。
- 重开工程后保存或测试，找不到 YDWE 界面层里的头文件（如 `AntiBJLeak/MainMacro.h`）。
- 保存地图后再切换触发器定义目录、修改函数库设置或函数库自动重载时，触发器会退回到打开地图时的内容。
- 地图用到通过“函数库…”安装的库时，重新选择触发器定义目录会误报“无法解析当前 WTG/WCT”并拒绝切换。
- 界面工作区导入示例被拒绝（例如示例触发器与其他类别里的同名触发器冲突）时，原因只进问题列表；现在状态栏也会显示。
- 贴图、模型选择器在屏幕下方打开时超出屏幕。
- 导入触发器时遇到其他类别里的同名触发器，提示里写出所在类别。

## 已知限制

- AudastraUI 函数库只支持经典 1.27a。
- 和 MemHack 一起使用时，重开任务、换图、回主菜单可能崩溃；关掉我们的运行库后同样会崩，属于外部问题。
- 地形：单个转角坡（内角、外角）能保存，游戏里的阻挡也和编辑器一致，但单位走不过单个转角坡；需要拐弯的通道请用两条分开的直坡。两条直坡相交拼成转角时会被拒绝。
- 地形：同一次保存里既换贴图槽、又用新贴图画坡会被拒绝，分两次保存即可。
- 地形改动保存后用原版编辑器重新打开的核对还没做完；纹理过渡、悬崖接缝，以及原版光照、阴影、雾和粒子的整体还原仍在逐项核对。
- 更新编辑器后，请在触发器的“函数库…”里把 AudastraUI 也更新一次，再保存带界面的地图；版本不一致时保存会提示。
