# Audastra 0.5.1

修复内置助手选用 Gemini（Google AI Studio）时无法使用的问题，以及物编选模型时选择面板卡死的问题。

## 物编

- 在物编里点开模型字段的选择面板后，右侧“预览近似”一显示出模型，整个面板就卡住不能再操作，只能按 Esc 关闭。现在预览正常显示，面板可以继续搜索、切换和应用。
  - 原因：选择面板用了半透明的圆角窗口，Windows 不会把里面的 3D 预览画面合成到屏幕上。预览区成了一个透明的洞，鼠标点上去会漏到后面的窗口。现在这个面板改用不透明的窗口。
- 有些模型在预览里显示不出来，这个问题在 0.5.2 集中处理。

## 助手

- 选用 Gemini 模型时，每次请求都会被拒绝，并报 `reference to undefined schema`。现在可以正常查询和编辑地图。
  - 原因：触发器查询工具的参数定义里，有一处引用放错了位置。Gemini 检查严格，会拒绝整次请求；其他服务商不检查这一点，所以以前没出问题。
- 编辑器 MCP 服务（`war3-map-mcp`）里的同一个工具也一并修正。外部 Agent 使用严格校验的客户端时不会再报错。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。
