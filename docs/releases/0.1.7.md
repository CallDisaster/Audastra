# Audastra 0.1.7

本次修复旧版升级误报 `UPDATE_ADS_REJECTED`，并继续改善世界预览中的地表过渡和模型贴图。

## 更新安装

- 更新器可以识别正常的 Windows 下载来源标记，不再将合法的 `Zone.Identifier` 一律当成异常数据流拒绝。
- 更新、回滚和备份清理会核对来源标记。用户文件、目录和空目录的标记按原字节保留；未知数据流、来源变化或被修改的程序文件继续明确拒绝。
- 旧客户端中的检查逻辑不能通过下载新包改变。若旧版出现此错误，请将完整包解压到新目录，保存并退出旧版后启动新版；原目录及其中的地图和工程会保留。需要继续使用原目录时，按[旧版升级修复说明](../LEGACY_UPDATE_REPAIR.md)完成一次迁移。

## 世界预览

- 减少地表预览的基础网格占用，改善大地图中纹理过渡因预览预算不足而被省略的问题。
- 改善地表和模型斜视时的纹理采样，保留模型纹理原有的平铺与边缘处理标志。
- 修正悬崖形变后的法线计算。
- 修复追加模型变体没有继承已有材质状态模式而导致预览被拒绝的问题。

## 仍在改进

- 纹理过渡、悬崖与地表接缝，以及原版光照、阴影、雾和粒子的整体保真仍需继续逐项核对。
- 地形真保存仍只开放明确支持的有限操作；通用通行、阴影和小地图自动重建尚未完成。编辑器内往返不代表已通过原版编辑器重开或真实游戏运行。
- 部分缺失或损坏资源仍会显示诊断。请继续在地图副本上试用。
