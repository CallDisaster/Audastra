# Audastra 0.5.8

这一版主要更新内置 AI 助手：长任务不再中途丢会话或假装做完，上下文会自动压缩，能看到上下文用了多少，可以给地图写记忆，也可以接自己的 MCP 服务器。另外导入管理器可以直接替换文件。

## 内置 AI 助手

- 会话不再丢失：
  - 发出的提问会先保存再交给模型。运行失败、手动停止或压缩会话时，原来的长提问都还在。
  - 失败且模型一句也没回的提问，下次发消息时不会被重发。
  - 会话记录太大（超过 8 MB）时，先删掉较早的思考过程，再删最早的记录，并在历史顶部写明删了多少条。以前这种情况会整份保存失败。
- 长任务（例如一次建一组触发器）不再半路显示“本轮完成”：
  - 思考型模型的输出上限按模型调整，不会被思考过程用光。
  - 回复被截断时会接着写，有次数上限。
- 上下文压缩：
  - 接近上限时自动压缩较早的回合，原始需求和约束会保留下来。
  - 也可以点“压缩会话”或输入 `/compact` 手动压缩。
  - 当前回合里很长的工具调用链也会被压缩。如果摘要里包含当前提问之前的旧回合，会注明先后，和当前提问冲突时以当前提问为准。
- 右侧检查栏：
  - 显示上下文的构成：消息、内置工具、MCP 工具、系统提示词、技能、记忆文件，以及离自动压缩还有多少。
  - 显示缓存命中率。
- 思考强度：
  - 输入栏右下角，模型选择框旁边可以切换思考强度，也可以输入 `/effort`。
  - 只列出接口或内置目录里明确支持的档位。识别不到时，可以在设置里自己勾选这个模型支持哪些档位。
  - 模型名最后一个字不再被截掉。
- 地图记忆：
  - 地图旁边的 `<地图名>.memory.md`（目录工程用 `MEMORY.md`）会提供给助手，用来记住这张图的约定；另有一份全局记忆。
  - 输入 `/memory` 打开记忆编辑窗口。
  - 别人地图里带的、或在编辑器外改过的地图记忆，要你在记忆编辑窗口里看过并保存一次才会提供给助手。助手也不能覆盖这种未确认的记忆。
  - 助手不能改全局记忆。
- 自定义外部 MCP 服务器：
  - 支持本地进程（stdio）和 HTTP 地址两种。可以直接粘贴常见的 `mcpServers` 配置导入。
  - 密钥存进系统凭据库，不留在设置文件里。粘贴导入时，环境变量或 Authorization 请求头里的密钥会自动移进凭据库；启动参数或地址里写着明文密钥的配置会被拒绝。
  - 每个服务器可以设最低权限（只读、编辑、保存、全部）。只有内置 AI 已开启、该服务器已启用、当前权限也够时才会启动或连接。
  - 本地进程只继承必要的环境变量。关闭编辑器时这些进程会一起结束。

## 导入管理器

- 文件右键新增“替换文件…”：选一个本地文件替换内容，原来的路径和名字都不变。默认只列同类型文件，选了不同类型会先确认。可以撤销，保存地图时写入。
- 修复：资源改名后，再往新路径放一个文件（替换或导入同名文件），以前保存会失败，现在能正常保存。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 外部 MCP 服务器：
  - 每个服务器只能保存一条密钥；HTTP 方式只支持 Authorization 请求头。
  - `npx` 这类命令要写成 `cmd` 加参数 `/c npx …` 才能启动。
  - 设置里格式不对的 MCP 条目在加载时会被跳过，再保存一次设置后就不在了。
- 界面编辑器新建界面仍需一秒多，下个版本继续优化。
- 世界页打开后，模型仍是全部读完才一起显示，还不能先显示镜头附近的模型。
- 界面编辑器里游戏自带的原版样式还没在游戏里逐个核对，暂不在创建卡片里列出。
- 删除物体时，按变量或函数取值的触发器参数、地图导入的脚本无法静态检查，需要你自己确认没有用到。
- 少数模型预览仍显示不出来，原因见 0.5.2 说明。
