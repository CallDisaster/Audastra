# Audastra 0.1.9

本次修复程序内更新被拒绝的问题。

## 升级

- 修复用部分解压工具解压后，检查更新提示“下载来源数据流无法完整读取或不是受支持的ZoneTransfer元数据”、无法在程序内更新的问题。这些工具会在文件的下载来源标记末尾多写一个结束符，之前的版本把它当成异常数据拒绝了。
- 0.1.8 及更早版本若遇到上面的提示，请下载 0.1.9 完整包解压到新目录使用，设置会自动沿用；从 0.1.9 开始可以正常在程序内更新。

## 仍在改进

- 小地图和干地高度保存还没有完成原版编辑器重新打开和进游戏的验收；地形的水、悬崖和贴图修改仍不能真正保存。
- 纹理过渡、悬崖与地表接缝，以及原版光照、阴影、雾和粒子的整体保真仍在逐项核对。
- 请继续在地图副本上试用。
