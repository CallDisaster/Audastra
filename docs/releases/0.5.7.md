# Audastra 0.5.7

补丁版：界面编辑器操作不再卡顿，触发器改名失败不再无声无息，世界页打开地图后在后台先准备好，小地图更接近游戏里的样子，同时补上 KKWE 运动器剩下的几条动作。

## 界面编辑器

- 挪位置、改名、改属性以前每次要卡五秒左右（大地图上更明显）。原因是每改一次界面，编辑器都会把整份物编目录重建一遍，还会重复检查两次运行库。现在只改界面时这些都会跳过，一次修改在 0.1 秒左右完成；新建界面也从六七秒降到一秒多。
- 打开大地图时，运行库检查不再每次都把整张地图重新读一遍。

## 触发器

- 修改类别（文件夹）或触发器名字时：
  - 以前有时打字没反应，或者改长一点的名字时什么提示都没有就失败了。现在名字只会因为真实原因被拒绝（例如重名），被拒绝时问题列表里会写明原因，并在原位置重新打开输入框，保留你刚输入的文字。
  - 输入框打开时，按 Ctrl+G、Ctrl+T、Insert 等不会再误触发新建或复制。
  - 当前选中右侧状态列时按 F2 也能改名。

## 世界

- 打开地图后，世界页会在后台先把地形和模型准备好，切到世界页时不用再从头等地形和全部模型。
- 建筑的地面贴花不再盖住单位和特效（例如冰霜塔顶上的特效）。
- 小地图：
  - 移动视角时视窗框不再闪烁，镜头压得很低时也不会消失。
  - 和游戏里一样，建筑的点比普通单位大。是不是建筑按物编判断，和保存地图时生成小地图图标用的是同一套判断。
  - 金矿、中立建筑、开始位置显示游戏里真正的小地图图标。
  - 单位点和小地图图标默认打开。

## 物编

- 已修改的字段以前按改动先后排在最前面，同一组字段可能被拆开（例如先改了按钮位置 Y、后改 X，两行就隔得很远）。现在所有字段一起按分类和名称排序，成对的字段始终挨在一起。

## 保存

- KKWE 运动器的“应用到单位 / 物品 / 可破坏物 / 特效 / 装饰物”、更新和到达回调、移除运动器以及“清除当前运动器”现在按 KKWE 的方式生成，用到它们的地图可以保存了。“清除当前运动器”和 KKWE 一样只在运动器回调里生效，写在别处时保存结果里会提示。

## 升级

- 0.3.0 及以后的版本可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 世界页打开后，模型仍是全部读完才一起显示，还不能先显示镜头附近的模型。
- 界面编辑器里游戏自带的原版样式还没在游戏里逐个核对，暂不在创建卡片里列出。
- 删除物体时，按变量或函数取值的触发器参数、地图导入的脚本无法静态检查，需要你自己确认没有用到。
- 少数模型预览仍显示不出来，原因见 0.5.2 说明。
