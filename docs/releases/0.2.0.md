# Audastra 0.2.0

本次更新让 Agent 能更可靠地帮你改触发器和物编，并开始在测试中直接操作游戏。另外支持了更多旧版 YDWE 分支地图的保存，也开始支持水面和地形通行的保存。

## Agent 改触发器

- **整图检查**：Agent 改完触发器后，可以先按保存时的方式生成整张地图的脚本并做完整检查，不写入地图。报错会直接指到哪个触发器、导出文字的第几行第几列，不再只给生成脚本的行号。
- **一个功能一次写完**：一段文字里同时声明这个功能用到的变量和多个触发器，整批写入、一次撤销。新触发器可以指定放在哪个触发器后面。
- **只改一小段**：按行号替换触发器里的几行，并核对这几行原来的内容，防止改错位置。
- **先预览再写入**：可以先看每个触发器具体会改哪些行，再决定是否写入。
- **直接写名字**：触发器、区域、镜头、声音可以直接写地图里的中文名，不用写下划线形式的脚本名；导出时也优先显示中文名。两个中文名会变成同一个脚本名时，保存会提示冲突。
- **调整位置更简单**：移动触发器或类别只需给出放在谁前面或后面。
- 可以查询各类型的预设值，以及某个函数在本图里的真实用法。
- 触发器整体导出为紧凑文字，Agent 读写一个完整触发器更省事；参数可以直接写技能编号和函数调用。
- 修复：地图里引用了预设的区域、镜头、声音或可破坏物时，Agent 改写这类触发器会被拒绝。
- 修复：Agent 新写的单行“注释”动作被当成新代码拒绝。
- 修复：在地图所在文件夹里放一份备份等无关文件后，编辑器误以为地图被其他程序修改，物编查询被锁住。

## Agent 改物编

- 对象字段可以读成一行一个字段的文字，例如 `生命值 (uhpm) = 300`；引用其他对象的字段会在行尾注明对象名。
- Agent 只写要改的几行即可修改，整批检查、整批生效，出错时指出第几行，可以撤销。

## Agent 测试地图

- Agent 可以启动单人测试，测试结束后结束游戏，测试副本会自动清理。命令行测试也支持结束游戏（`--stop`）。
- 实验功能：在 Lua 地图的测试中，Agent 可以执行一段触发器动作并读回变量的值。JASS 地图暂不支持。

## 旧版 YDWE 地图

- 支持雪月等旧版 YDWE 分支框架的地图保存：脚本重建、编译和重新打开都走同一套通用规则，不针对某个分支写死。
- 删除导入文件前，会先查找脚本、触发器、物编和界面文本里是否还引用它。

## 地形保存（预览）

- 世界页新增浅水、深水笔刷，可以保存，保存后也能撤销、重做。
- 修改贴图、普通悬崖和水深后，按本机游戏的实际资源重新生成通行数据，原有的通行限制会保留。
- 跟随地形高度的摆放单位、装饰物，保存时会一起更新高度。
- 修复：新建的地图画水后无法保存。
- 部分可破坏物的通行效果会按地图物编计算。

## 仍在改进

- 地形保存还没有完成原版编辑器重新打开和进游戏的验收，请先在地图副本上使用并保留备份。
- 普通装饰物、特殊地形装饰物和坡道附近的修改暂时不能保存，会明确提示原因，工程仍可保存。
- 小地图和阴影数据还没有按原版方式重建。
- 纹理过渡、悬崖与地表接缝，以及原版光照、阴影、雾和粒子的整体保真仍在逐项核对。
