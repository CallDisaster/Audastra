# Audastra 0.5.0

界面重做，并把之前记下“以后再做”的功能补齐：外部依赖接口、跨多次保存撤销、小地图图标和通行图层、地形块旋转镜像、多选。

## 界面

- **整体界面重做。** 主题、主窗口、起始页和各模块页面都换了新样式。
  - 选中颜色和鼠标悬停颜色分开了，不会再分不清哪行被选中。
  - 表格筛选后，批量操作只作用于筛出来的行。
- **多选。** 触发器目录和语句树、变量、世界、物体、声音、设置都支持 Windows 式多选：按住 Ctrl 逐个点，按住 Shift 连选。蓝图也可以多选后一起拖动。
- 助手窗口显示实际的连接、用量和工具状态。

## 撤销

- **保存后还能接着撤销。** 地形、摆放、地图设置、区域、镜头、声音、物编、触发器和变量的撤销记录随 `.forge` 工程保存，关闭再打开工程后也能撤销、重做。
- 撤销到较早位置再保存，地图写入当时的内容。
- 有容量上限：地形和地图数据最多 128 步；物编和触发器每个撤销栈最多 64 步。超出时会提示最早还能撤回到哪一步。

## 地形

- **地形块粘贴可以旋转和镜像。**
- 坡道：
  - 连接坡道可以连续反向拐弯（之字形）；
  - 和原版一样，用浅水淹没直坡或用“降低一级”降低坡道中点，会清除整条坡道；
  - 两级梯田的下缘可以画直坡。

## 小地图

- **小地图图标可以编辑。** 增加、删除、拖动位置，可以选图标类型、改颜色；保存后在选图界面的小地图里能看到。
- **“通行”图层可以用了。** 配色和原版编辑器“输出微缩地图 → 包括路径地图”一致：
  - 不可走为红、不可飞为绿、不可建为蓝，组合相加；
  - 例如浅水为蓝；深水和悬崖边为品红；地图边界为白。
- 通行图层显示的是这次保存会写出的通行图。

## 触发器

- 参数要选触发器时，可以直接从已有触发器里选。
- 改触发器名字时，只有代码真的用到旧名字才会拦下，不会再误拦。

## 战役

- 战役里的地图可以多选后一起移除。

## 外部依赖（DzAPI、EX 接口）

地图测试现在可以用 YDWE 的 EX 系列接口和 DzAPI。

**需要的文件编辑器不附带，请在反馈群（1127618143）的群文件里下载“外部依赖”。** 把里面的 `YDWE`、`KKWE` 两个文件夹放进外部依赖目录即可。

- 外部依赖目录默认是安装目录下的 `外部依赖` 文件夹，也可以在“应用设置 → 地图测试”里改。在线更新不会清掉它。
- 自己已有这些文件的，不用下载，按下面的位置放进去即可。只用其中一种，就只放对应的文件夹。
- **YDWE 的 EX 系列接口：** 放到 `外部依赖/YDWE/`，共八个文件：
  - `ydbase.dll`、`lua53.dll`、`ydwar3.dll`、`msvcp140.dll`、`vcruntime140.dll`，在 YDWE 的 `bin` 文件夹里；
  - `yd_loader.dll`、`yd_jass_api.dll`、`yd_lua_engine.dll`，在 YDWE 的 `plugin/warcraft3` 文件夹里。
  - 其中 `msvcp140.dll`、`vcruntime140.dll` 是 YDWE 自带的运行库，电脑没装 32 位 VC++ 运行库时需要它们。
- **DzAPI：** 放到 `外部依赖/KKWE/`，只需要 `dz_w3_plugin.dll`，在 KKWE 的 `插件` 文件夹里。
- DzAPI 只在 1.27a 上可用。
- 测试时不会往游戏目录里写任何文件。
- 这些 DLL 会直接在游戏里运行，只放可信来源的文件。
- 其他接口可以按 `docs/EXTERNAL_DEPENDENCIES.md` 写提供者声明（`provider.json`）接入。

## Lua 测试

- 自带 Lua 环境在 1.27a 上可以重开同一张地图继续测试，上一局的状态不会带进下一局。
- 用 YDWE 的 Lua 引擎测试时，Lua 里 `|AHhb|` 这种四字码写法会在测试副本里自动换成整数。YDWE 的 Lua 引擎本身不认这种写法，以前整个文件会不执行，退出时还会崩溃。地图原文不变。

## 命令行

- `map-create` 新增 `--header-code`，可以写地图脚本头，用来声明扩展接口。
- `map-test --lua-folder` 以前会报目录错误，修好了。

## 升级

- 0.3.0、0.3.1、0.4.0、0.4.1 可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。

## 已知限制

- 本编辑器通行笔刷画的限制，原版编辑器不认识。地图在原版编辑器里保存后，这些限制会被清除。
- 小地图通行图层只有原版默认的显示方式。原版“查看 → 路径-海路”那种显示没有做。
- 地图实际用 YDWE 或对战平台的 Lua 引擎运行时，Lua 里不要写 `|xxxx|` 四字码，请写成整数。测试时的自动转换只作用于测试副本。
- “大图上部分水边悬崖壁显示发黑”仍没能复现。如果你遇到，请截图发到群里，并说一下刚才做了什么操作。
- 其余限制同 0.4.1。
