# Audastra 0.1.8

本次修复部分使用 memory_hack 函数库的 YDWE 地图无法保存的问题，保存时会按原版规则重建小地图，并改进 Agent 直接处理地图包的能力。

## 保存

- 修复模板里 `<?= ?>` 写入带多个返回值的表达式（例如 memory_hack 里的 `math.modf`）时提示“只能写一个值”并中止保存的问题。现在与 YDWE 一致，只取第一个值。
- 放宽大型旧地图的触发器数量上限，触发器很多的旧图不再因为这个上限无法保存。
- 保存、另存为和新建地图时会按原版规则重新生成小地图。遇到暂不支持的内容（例如特殊装饰物）时保留原来的小地图并给出提示，照常保存；作者自己导入的小地图不会被覆盖。同样的地图内容每次保存得到相同的小地图。
- 只修改干地高度、且通行结果不变时，原有的通行、阴影和小地图图标文件原样保留。
- 补回导入文件时，旧工具写下的标志不明的导入记录可以正确对应到补回的文件。

## 物体编辑器

- 文本字段的值来自地图字符串表时，编辑框显示实际文字，不再显示 `TRIGSTR_` 编号。不修改直接确认时保留原引用；修改后直接写入新文字。

## 世界预览

- 改善荒芜地表、悬崖模型、模型贴图层级的显示，资源读取失败时给出更明确的原因。

## Agent 与命令行

- 独立 MCP 服务可以直接查询 `.w3x/.w3m` 地图包的地图数据和七类物编，不需要先展开。
- 新增把地图包展开成工作区的入口（CLI `archive-expand`、MCP `archive_expand`），展开后可修改物编和触发器，再写回新的地图包。
- 独立 MCP 服务可以添加和删除导入文件。删除前会查找脚本、物编、模型和界面文本里是否还写着这个路径，找到时默认拒绝并列出位置。
- 原始触发器数据可以按单个触发器分页查询，大型旧地图默认即可读取。
- 反馈新增“工具不好用”“兼容缺口”两类；MCP 帮助改为 UTF-8 输出。

## 升级

- 0.1.7 可以直接在程序内更新到 0.1.8。
- 更早的版本若更新时出现 `UPDATE_ADS_REJECTED`，请下载完整包解压到新目录，保存并退出旧版后启动新版；原目录及其中的地图和工程会保留。说明见[旧版升级修复说明](../LEGACY_UPDATE_REPAIR.md)。

## 仍在改进

- 小地图和干地高度保存还没有完成原版编辑器重新打开和进游戏的验收；地形的水、悬崖和贴图修改仍不能真正保存。
- 纹理过渡、悬崖与地表接缝，以及原版光照、阴影、雾和粒子的整体保真仍在逐项核对。
- 请继续在地图副本上试用。
