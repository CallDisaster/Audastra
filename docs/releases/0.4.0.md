# Audastra 0.4.0

这次更新主要有五块：
- **Lua：** 可以关联外部文件夹，用 VS Code 写；
- **h-lua：** 编辑器内置 h-lua 工程的打包和测试；
- **界面编辑器：** 能隐藏、移动、缩放原版界面，自己的界面能复制粘贴；
- **小地图：** 世界页加了小地图，没保存的修改也能实时看到；
- **地形：** 能改地形并保存的地图更多了，大图保存快了约 4 倍。

## Lua：关联外部文件夹

- 在“触发器 → Lua 脚本”里点“关联外部文件夹…”：
  - 空文件夹会先收到地图里现有的 Lua；
  - 非空文件夹会列出两边不同的文件，由你选以哪边为准，不会静默覆盖。
- 关联后可以直接用 VS Code 等编辑器写 Lua：
  - 外部保存后，编辑器自动读入；
  - 编辑器里应用的修改也写回文件夹；
  - 两边同时改了同一个文件，会让你选保留哪份。
- 保存地图时，把文件夹里的 .lua 存进地图。文件夹里删掉的文件，保存前会列出来，确认后才从地图删除。
- F9 测试和热重载都从文件夹读。勾了“保存后自动热重载”时，在 VS Code 里保存也会自动热重载。
- 文件夹找不到时（比如地图拷到别的电脑）：
  - 继续用地图里的 Lua，关联设置保留；
  - 文件夹回来后点“重新连接”即可。
- 关联路径按相对地图文件的位置记在地图里。
- 命令行 `lua-folder` 和 Agent 工具 `lua_folder_*` 用同一套服务。
- 测试运行中，如果游戏里还是旧代码，“热重载”按钮会用强调色提醒。

## h-lua 工程

- 关联的外部文件夹里有 `main.lua`，并且有 `hslk/` 或 `map/w3x` 时，会识别为 h-lua 工程。识别后出现工具条：检查、构建测试图、测试、构建、发布版、名称与 ID 表。
- 在“应用设置 → 地图测试”里指定你自己的 h-lua 框架目录。h-lua 是 AGPL-3.0 许可，**Audastra 不附带 h-lua**，也不运行它自带的 sdk.exe、YDWE 或 w3x2lni 程序。打包工具是 Audastra 自己实现的。
- 三种目标：
  - 测试版：带调试控制台；
  - 普通版：写原生物编；
  - 发布版：物编压成 SLK。
  - 三种都把框架和你的代码打进地图。
- F9 先构建测试图再进游戏。在 VS Code 里改了 `scripts/` 或 `main.lua` 可以热重载；改了 `hslk/` 会提示“需重新构建”。
- 和 h-lua 原工具的差别：
  - 实数不再截成两位小数，字符串正确转义；
  - ID 用完了会报错；
  - 字段写在不存在它的物体类型上（比如给物品写“种族”）时不写入物编，并逐处列出警告；
  - 带攻击 1/攻击 2 之分的字段要写带下标的键名（如 `Missileart_1`）。只有不改变结果的写法会放行，并给出警告。
- 自带 Lua 环境补上了 h-lua 启动要用的接口：物编读取、全局变量写入、句柄查询、控制台输出等。
- **仍不支持：** DzAPI、EX 系列扩展接口。h-lua 依赖它们的伤害、属性、同步、帧界面在自带环境里不会生效，测试信息里会列出来。
- 闪电和漂浮文字可以用。漂浮文字和 JASS 规则相同：销毁或过期后再用旧值，可能作用到复用这个编号的新漂浮文字。
- 天气效果暂不支持：原版用无效的天气类型创建时游戏会直接崩溃，安全判定还没做好。
- h-lua 官方的 helloworld 原样能打包、进游戏，漂浮文字能正常显示。用到 DzAPI 的部分仍会在测试信息里列出。
- 命令行有 `hlua-inspect`、`hlua-build`、`hlua-ids`、`hlua-test`、`hlua-new`，Agent 用同一套服务。详见帮助文档“h-lua 工程”。

## 界面编辑器

- **原版界面可以调整了。** 选中原版部件后，可以隐藏、移动、缩放、改透明度，也可以拖动或“恢复原样”，撤销重做照常。生成的自然 T 会在地图开始时应用这些调整。
- 每个部件都在 1.27a 游戏里核对过，下表就是核对结果。没有通过的项，编辑器里标“不支持”，生成触发器时会拒绝。

| 原版部件 | 隐藏 | 移动 | 缩放 | 透明度 |
|---|---|---|---|---|
| 资源栏、顶部按钮栏、小地图旁 5 个按钮、头像、技能栏、6 个物品格、英雄栏、信息栏 | ✓ | ✓ | ✓（需同时指定位置） | ✓ |
| 小地图 | ✓ | ✓ | — | — |
| 昼夜指示 | ✓ | — | — | — |
| 控制台整体、聊天消息 | — | — | — | — |

- 有模板的原版部件，可以右键“复制为自己的界面”。
- **自己的界面可以复制粘贴**（Ctrl+C / Ctrl+V 或右键）：
  - 子节点一起复制，编号自动去重；
  - 数值、状态、事件里的引用跟着改；
  - 可以跨界面描述粘贴。
- 改原版界面的功能（比如改原版按钮点下去做什么）不支持，请用自己的按钮加触发器实现。

## 小地图

- 世界页左下角有小地图了，分“当前编辑”和“已保存”两个页签：
  - “已保存”显示地图文件里实际存的那张；
  - “当前编辑”把还没保存的修改也画进去，改完半秒左右自动刷新。
- 刷新时先显示上一张图，标“更新中…”，新图出来再替换。
- 荒芜、区域、单位、开始位置、图标可以分别开关。“通行”图层暂不可用：原版通行图的颜色还没核实，选了会直接提示。
- 白框标出当前看到的范围，点一下或拖动就把视角移过去，不算一次修改。
- 物编改了不保存，当前小地图也会跟着变。
- 小地图还在生成时关闭地图，大图上原来要等约 11 秒，现在一秒左右。
- 167 张测试图里，能自动生成小地图的从 149 张增加到 164 张。

## 地形

- **大图保存快了约 4 倍。** 343 MB 的大图改一处地面后保存，从约 120 秒降到约 29 秒；打开时窗口卡住的时间从约 12.6 秒降到约 3.2 秒。
- **刷完浅水、枯萎、悬崖后，通行数据马上更新，** 不用等保存。结果和保存时生成的逐字节一致，撤销、重做也跟着变。大图上刷一笔的总耗时从约 12.4 秒降到约 6.9 秒。
- **尺寸 3、尺寸 5 的方台边可以做直坡了。** 保存结果和原版编辑器逐字节相同。
- **修复：地形还在读取时刷一笔，编辑器会退出。**
- 更多旧地图能改地形并保存：
  - 混乱之治时代的地图边界；
  - 旧版地图信息格式；
  - 缺通行文件的地图（会自动补上）；
  - 更多坡道交汇形态；
  - 固定角度装饰物的阴影。

## 装饰物、区域、镜头

- 装饰物可以缩放了。世界页右侧属性栏可以直接改，Agent 也能移动和缩放已经放好的装饰物。
- 带外部脚本的地图也能新建区域和镜头了。编辑器会检查导入的 JASS/Lua 脚本，确认新名字不和里面已有的名字冲突。

## 升级

- 0.3.0、0.3.1 可以在编辑器里“检查更新”直接升级。
- 0.2.0 及更早版本请从发布页手动下载便携包，原因见 0.3.0 说明。
- 游戏内界面运行库随本版更新到 0.4.0，原版界面调整要用新运行库。
- 用 0.3.x 存过界面运行库的地图：
  - 本版仍带 0.3.0 运行库，这些地图照常能改、能保存、能测试；
  - 在“函数库…”里把 AudastraUI 更新到新版后，保存时会提示把地图的运行库切换到 0.4.0，点“切换到 0.4.0 并保存”即可。

## 已知限制

- 坡道只支持有原版依据的几种形态：任意 S 形坡道不行，水进入直坡范围时会拒绝。
- 复杂悬崖或原版不支持算阴影的装饰物旁边，“计算阴影并保存”会被拒绝并说明原因，不影响普通保存。
- 167 张测试图里还有 69 张不能改地形并保存，每张都有记录在案的原因。
- 还没做：
  - 小地图通行图层、小地图图标编辑；
  - 地形块复制后旋转或镜像；
  - 跨多次保存一直撤销回去。
- 大图上部分水边的悬崖壁可能显示发黑，原因还在查。
