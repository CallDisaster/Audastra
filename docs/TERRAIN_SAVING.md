# 地形保存

世界页面中的修改进入同一撤销历史，可以保存到工程，也可以通过“保存地图”或“另存为”写入地图。编辑器、命令行和 Agent 使用同一套地图保存检查。

当前支持：

- 干地高度和荒芜修改。
- 地面贴图变体调整。
- 换成通行属性相同的地面贴图，包括替换地面贴图槽位和追加已知贴图。保存时读取地图中生效的地面表；地图没有提供时读取配置的本机游戏资源，确认新旧贴图的步行、飞行和建造属性一致。
- 已有水面的高度调整，前提是没有跨过浅水、深水或覆水边界，周边也没有坡道、边界或未知标志。涉水高度修改遵循同一检查。
- 已有悬崖的层级微调，前提是周边各地格的通行阻断轮廓、水深分类和覆水状态都不变，且没有坡道或边界。

这些操作保留原地图通行文件中的所有字节及作者已有的额外限制。荒芜修改只同步对应的荒芜位。保存前会再次检查实际资源和最终成员，保存后独立回读确认。

小地图随正常保存自动重建；遇到生成器暂不支持的内容时会保留原小地图并提示原因。作者导入的 BLP/TGA 小地图会保留。阴影保留上次计算的结果；单位摆放和可玩范围未变时，小地图图标也保留。

改变地面通行属性、跨越水深通行阈值、创建或移除水面、改变悬崖通行阻断轮廓和坡道等操作还需要完整通行重建。遇到这类变化时，编辑器会说明原因并阻止地图写回；可先保存工程，或撤销相关笔划后保存地图。

通行不变的地形修改暂时需要与资源导入、物编、单位摆放和地图范围修改分开保存。资源缺失、来源改变或无法确认属性时也会拒绝写回，避免使用猜测值。

命令行的 `map-edit-save` 可以使用 `--stroke texture circle 32 32 0 Lgrs` 更换地面贴图，或使用 `--stroke water-height circle 32 32 0 170` 调整已有水面基础高度；其余地图路径、来源 SHA 和工具来源参数仍按命令帮助填写。MCP 的 `save_map_edit_candidate` 使用 `kind:"texture"` 与 `ground_texture`，或 `kind:"water_height"` 与 `water_height`；所有入口都会执行相同的通行检查。

以上保存与编辑器内回读检查不代表已通过原版编辑器或游戏验收。涉及旧版 YDWE、memory_hack 或自定义资源的地图，请使用副本在原版编辑器重新打开，并在游戏中核对通行、外观及触发器行为。
