# R07 · 物体管理器、触发器目录与停靠工作台

预览：`npm --prefix editor-ui run dev -- --host 127.0.0.1 --port 5178`。原版数据导入方法见 README-R06（本轮修正分类名后已重新生成）。

## 用户反馈对应

| 反馈 | 处理 |

| 物体管理器基本看不出哪里引用了对象 | 新的工程级引用索引，右侧按触发器 / 物体 / AI 分组列出每一处引用的完整语句，点击直接跳到对应语句 |

| 触发器文件夹是假的，不能新建文件夹、不能删除触发器 | 目录改为真实文件夹：新建 / 重命名 / 删除 / 拖动排序 / 移动 / 复制粘贴 / 创建副本 |
| “允许”“初始打开”无法设置 | 编辑区顶部常驻信息条（对应原版触发器面板上方）+ 目录右键菜单；代码生成已按两者处理 |

## 引用索引（`referenceIndex.ts`）

- 一次遍历触发器语句、触发条件与 If 条件、物体字段、变量初值、放置实例、AI、声音，建立“记号 → 引用位置”和“函数 → 调用位置”。触发器语句的引用文字就是原版格式的整句（“单位 - 创建 4 个 守卫步兵 在 进攻出生点”）。
- 表达式与自定义脚本字段按标识符拆分，`udg_` 前缀对应全局变量，因此 `wave < maxWaves` 这类表达式中的变量也会计入。
- 禁用的触发器 / 语句 / 条件中的引用仍然列出，但标为删除线（不生成代码）。
- 物编“静态引用”、物体管理器、删除触发器前的检查共用同一份索引；旧的 `referencesTo` 保留为包装函数。
- 仍然只统计工程数据中的直接引用；自定义脚本文本、字符串拼接等动态引用不在其中，界面上始终注明，不作为安全删除依据。

## 物体管理器（`ObjectManager.tsx`）

- 物体各页列出地图中实际用到的物体：自定义、已修改的原版、被引用的原版；从物编跳过来的原版物体即使没有引用也会列出。列：名称、ID、状态、放置数、引用数，点表头排序。
- 过滤：全部 / 自定义 / 已修改 / 引用的原版 / **未使用**（没有引用也没放置的自定义物体）。变量、区域、声音同样有“未使用”。
- 右侧详情：被引用（按触发器分组，可折叠）、放置在地图上、使用了（例如单位用到的技能、触发器用到的变量和物体）、触发器调用的函数（点击转到函数页）。
- 地图概况按原版“物体管理器-地图概况”列出数量，另加“清理建议”：未使用的变量、未使用的自定义物体、已禁用的触发器，点击直接进入对应过滤。
- 键盘：搜索框 ↓ 进入列表，↑↓ 选择，Enter 打开编辑器。离开再回来时保留页签、过滤和选中项。

## 触发器目录（`TriggerTree.tsx`、`triggerFolders.ts`）

- 文件夹为真实数据：`project.triggerFolders` 保存顺序并保留空文件夹；`graph.folder` 仍为文件夹名，旧工程不需要迁移。
- 新建触发器 / 文件夹按原版命名（“未命名触发器 001”“未命名类别 001”），新建后立即进入重命名；重名在输入框下方提示，不接受。
- 删除触发器：没有被引用时直接删除（可 Ctrl+Z）；被“运行触发器”等语句引用时先确认并列出引用位置。删除文件夹连同其中触发器，先确认，并列出文件夹外的引用。
- 拖动：拖到触发器上插在它前面，拖到文件夹上放进该文件夹末尾，文件夹之间拖动排序。
- 键盘：↑↓ 选择，←→ 折叠展开，F2 重命名，Delete 删除，Insert（或 Ctrl+T）新建触发器，Ctrl+G 新建文件夹，Ctrl+C / Ctrl+V 复制粘贴触发器，Ctrl+D 创建副本。提交、取消、删除后焦点留在目录，可以连续操作。浏览器会占用 Ctrl+T，原生端不受影响。
- 目录显示状态：禁用的触发器为删除线并标“禁用”，初始关闭标“关”。
- 编辑区顶部信息条：允许、初始打开、触发器注释（折叠显示首行）。取消“允许”后不生成代码，取消“初始打开”后生成 `DisableTrigger`。

## 停靠工作台（`DockShell.tsx`、`dockLayout.ts`、`moduleHost.ts`）

第一版是“左侧模块栏 + 顶部标签栏”，用户试用后指出两处问题：同一组模块在侧栏和标签栏各出现一次，点一下侧栏就在顶上多开一个标签，既占地方又显得笨重；切回物编时滚动位置回到顶部。第二版（R07b）改为：

- **一行顶栏**：工程名、返回、九个模块切换器、搜索、撤销/重做、保存、检查、函数定义、设置、布局。左侧模块栏和标签栏都去掉，主编辑区比第一版宽 72px、高 36px。模块常驻切换器里，没有“打开/关闭标签”这一层；Alt+1…9 与切换器顺序一致。顶栏变窄时先收起搜索与保存的文字，再只显示模块图标（悬停仍有名称和快捷键）。
- **位置**：每个模块只在一处——主编辑区（默认）、右侧停靠区或独立窗口。切换器上用底线标出主区正在显示的模块，用小图标标出在独立窗口或右侧的模块；点击它们会把窗口提到最前 / 在右侧激活。
- **拖动**：把切换器里的模块拖到编辑区空白处 → 独立窗口；拖到右侧出现的提示区 → 停靠到右侧；把窗口标题栏或右侧标签拖回顶栏 → 放回主编辑区。右键模块也有同样三项。
- **独立窗口**：拖动、八向缩放、双击标题栏最大化、收起为标题栏、停靠到右侧、放回主编辑区；点击任意位置提到最前（窗口之间的前后次序同 Windows）。浮动窗口始终在编辑区之上，需要看下面的内容时收起或放回。
- **布局按钮**（相当于 Photoshop 的“窗口 → 工作区”，但只占一个图标）：预设“单编辑区 / 触发器 + 物体管理器 / 物体 + 物体管理器 / 触发器 + 变量”，并列出当前不在主编辑区的模块，点击即放回。
- **状态保留**：打开过的编辑器一直挂载在自己的宿主节点里，布局变化只搬动节点，组件状态不丢。节点离开可见位置时浏览器会把其中的滚动条归零，因此搬走前同步记录所有滚动过的元素，放回后恢复（物编目录、字段表、触发器目录等）。只有通过引用或搜索“跳转到某个目标”时才重建该编辑器以定位目标。
- **返回**：Alt+← 或工程名旁的返回按钮。
- 布局（主区当前模块、右侧组、窗口位置与尺寸、每个模块上次浮动的尺寸）保存在本机浏览器，只是界面偏好，不写进工程；第一版保存的标签组格式会被安全忽略。
- 原生端映射：中央编辑区 + 右侧停靠组 + 浮动顶层窗口（Qt 停靠系统，浮动窗口由操作系统管理前后次序，可以拖到第二块屏幕）；顶栏切换器对应一条紧凑的工具栏，不另设侧栏。

## R07c · 物编目录对齐原版与暗色原生控件

用户反馈：暗色界面下滚动条与下拉列表是白色，选项文字几乎看不见；“人族”等文件夹无法折叠；目录结构应与原版一致（有“标准单位 / 自定义单位”母文件夹）。

- **文件夹无法折叠**：原因是当前选中物体所在的整条路径在每次渲染时都被强制展开（每类默认选中第一个物体，所以“人族”“人造物品”这类第一个分组总是折不起来）。现在用户点过的文件夹以用户为准，没点过的才默认展开根文件夹和当前物体路径；从搜索或引用选中物体时展开其路径，之后仍可自由折叠。每类的折叠状态分别记住。
- **目录结构**：两个根文件夹“标准X（数量）/ 自定义X（数量）”，自定义为空也显示。第一层分组按原版规则重新导出，并与原版计数核对：
  - 单位：人族 108、兽族 85、不死族 77、暗夜精灵族 78、中立 - 娜迦 19、中立敌对 292 与原版一致。规则：四个主种族与娜迦按种族，其余按 UnitUI 的 `hostilePal` 分中立敌对 / 中立被动。中立被动为 177，原版为 175（原版总数 834，本机数据 836，原版另外排除的 2 个单位规则尚未查明）。其下为 对战 / 战役 → 单位 / 建筑 / 英雄 / 特殊。
  - 技能：人族 52、兽族 69、不死族 70、暗夜精灵族 72、中立敌对 236（creeps）、中立被动 11（naga）、特殊 289（其余及物品技能），全部与原版一致；其下为 单位 / 英雄 / 物品。
  - 魔法效果、科技同样按 人族 / 兽族 / 不死族 / 暗夜精灵族 / 特殊（科技的娜迦为“中立 - 娜迦”），这两类尚未与原版截图核对。
  - 每一层使用各自的顺序（种族层“特殊”在最后，类型层 单位 → 建筑 → 英雄 → 特殊）。
- **隐藏物体**：原版的目录计数包含编辑器中隐藏的物体（例如兽族 85 = 84 + 1 个隐藏），因此默认改为显示，眼睛按钮可以隐藏它们。
- **暗色原生控件**：工作台根节点声明 `color-scheme`（暗色主题为 dark，浅色主题为 light），浏览器绘制的滚动条、下拉列表弹层、复选框随主题变化；下拉选项显式使用面板底色与正文色；滚动条改为细滚动条。去掉了各组件里写死的 `color-scheme:dark`，浅色主题不再被强制成暗色控件。

## 开发者视角发现并修正的问题

- 回车提交重命名后焦点掉到页面，接着按 Ctrl+G / Delete 没反应：改为同步把焦点还给目录，并防止输入框 blur 造成重复提交。
- 从物编跳到物体管理器查看一个没有引用的原版物体时右侧是空的：现在会列出该物体并明确显示“没有引用”。
- 拖成窗口后点击窗口内容不能提到最前：编辑器内容经 Portal 渲染，React 合成事件不经过窗口外框，改用原生捕获监听。
- 新窗口一半在屏幕外：新建窗口时完整放进工作区；缩小浏览器时窗口不超出工作区。
- 停靠后再拖出窗口会丢失上次尺寸：布局记住每个模块上次浮动的尺寸。
- 触发器信息条与视图同级使用相同 key 导致重复渲染警告：已修正。
- （R07b）侧栏与标签栏重复、占位：合并为一行顶栏切换器。
- （R07b）切换模块后物编滚动位置回到顶部：搬动前同步记录、放回后恢复滚动位置；最初用 scroll 事件记录，但后台页面不派发 scroll 事件，改为同步快照。
- （R07b）快速甩动拖放时右侧提示区还没出现就松手，结果变成独立窗口：松开时重新判定目标。
