# War3 Map Studio — 前端界面设计演示

> 2026-09-18 · 纯界面演示（无后端功能），展示现代化魔兽争霸 3 地图编辑器的预想不到形态。
> React + TypeScript + Vite + Tailwind。

## 设计理念

**视口即中心。** 传统 WE 把地形塞进一个小窗口、四周堆满文字面板；本设计反过来——
世界画面占据 70% 以上面积，所有工具以悬浮玻璃卡片或窄边栏环绕，文字最少化。

- **深色精致**：近黑背景 + 柔和圆角（8-14px）+ 毛玻璃悬浮控件 + 天空蓝单一强调色；
- **呼吸感**：面板留白充足，信息用图标、色块、进度条表达，不用密集文字表；
- **游戏感**：等距 3D 地形实时渲染（光照、水面微光、雪顶松树、单位呼吸光圈），
  小地图与主视口共享同一份世界数据。

## 界面结构

```text
顶栏      地图名 · 撤销重做 · AI助手 · 保存
┌──────┬──────────┬─────────────────────┬──────────┐
│工具栏 │ 调色板    │   3D 视口            │ 检查器    │
│地形  │ 笔刷/纹理 │   （悬浮控件环绕）     │ 属性/图层 │
│单位  │ 单位网格  │   左下小地图          │          │
│装饰物│          │   右下缩放            │          │
└──────┴──────────┴─────────────────────┴──────────┘
状态栏    自动保存 · 坐标 · 玩家数
```

- **地图工作室**：地形笔刷（纹理色板 + 大小/强度滑杆）、单位/装饰物调色板（图标网格）、
  区域/镜头列表；视口支持拖拽平移、滚轮缩放、方位角旋转、点选单位；
- **触发器**：节点画布 —— 事件(金) → 条件(紫，是/否分支) → 动作(蓝) 贝塞尔连线，
  左为触发器大纲，右为节点参数（彩色胶囊 = 可点击编辑）；
- **物体数据**：卡片画廊 + 类别胶囊筛选 + 右侧详情卡，取代密集字段表。

## 运行

```bash
npm install
npm run dev      # 默认 3000 端口，或 --port 指定
```
