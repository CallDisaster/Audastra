# R05 · 内置触发目录与“添加动作”面板

预览：`npm --prefix editor-ui run dev -- --host 127.0.0.1 --port 5178`（`.claude/launch.json` 的 `editor-ui` 已带 `--host 127.0.0.1`；此前只监听 IPv6 `::1`，所以 `127.0.0.1` 会被拒绝连接）。沿用 R04 工程与存储，不修改 C++。

## 内容

- **内置目录** `triggerCatalog.ts`：6 个事件（地图初始化、逝去时间、周期、任意单位死亡、进入区域、聊天消息）、5 个流程（If/Then/Else 多项条件、For 循环整数 A、For 循环整数变量、选取单位组/区域内单位做动作）、20 个动作（设置变量、等待、注释、自定义代码，以及单位、英雄、玩家、游戏、触发器、特效、声音、镜头）。每项含类别、语句模板、说明和 JASS/Lua 模板。目录在运行时并入（`withCatalog`），写回时按对象身份去除（`withoutCatalog`），工程文件不保存目录副本；工程中同 ID 的定义优先。
- **取值函数**：补充选取单位、凶手单位、最后创建的单位/单位组、触发玩家、输入的聊天字符串、单位位置、可用地图区域、整数转字符串、整数 A、整数/实数算术。算术的运算符在函数参数中是下拉选项。
- **添加动作/事件面板** `StatementChooser.tsx`：用于工具栏、右键和端口拖出三种入口。左侧类别（带数量），中间按名称/语句/类别搜索，底部显示所选项的语句预览、说明和 ID；↑↓ 选择，Enter 添加，Esc 关闭。插入传统视图时只列可执行语句，添加事件时只列事件。
- **传统视图**：If 行下方可直接编辑条件块（与触发条件同一套编辑、重排、禁用、And/Or），随后是“Then - 动作 / Else - 动作”。注释动作按原版以绿色斜体显示。“设置变量”和“For 循环整数变量”的变量参数只列变量（可就地新建并选择类型，可填数组下标）；“设置变量”的值类型跟随所选变量，例如选择单位变量后只列返回单位的函数。
- **蓝图**：If 节点显示条件摘要（如 `wave < 3`），点击后转到传统视图编辑。
- **代码生成**：模板语句就地展开子块；只有 Else 有动作时才输出 `else`；JASS 的“选取单位做动作”生成独立回调函数，Lua 生成内联闭包，回调中使用等待或动作局部变量时给出诊断。事件按模板注册；地图初始化事件在 `InitTrig` 中 `ConditionalTriggerExecute`。点、声音、触发器常量分别生成 `GetRectCenter(gg_rct_*)`/`Location(x, y)`、`gg_snd_*`、`gg_trg_*`，并提示需由地图后端提供这些符号。
- **修复**：读取已保存工程后状态栏立即显示“未保存”（校验会重排字段顺序，原来直接比较原始字符串）；现在以读取后的规范化结果作为已保存基线。读取时也会校验节点上的条件结构。
