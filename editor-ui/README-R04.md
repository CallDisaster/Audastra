# R04 · 传统 ECA 视图与触发条件

预览：`npm --prefix editor-ui run dev -- --port 5178`（或 `.claude/launch.json` 的 `editor-ui`），打开后进入“触发器 → 传统”。沿用 R03 工程与存储，不修改 C++ 或原生地图。

依据：09-23 对 YDWE 1.32.12.181229 触发编辑器、设置动作与取值对话框的只读截取，结论见 [最终前端方案 7.1 节](../docs/WORLD_EDITOR_RESEARCH_UI_HANDOFF_2026-09-23.md)。

## 修复的问题

- 旧传统树把每条“完成”连线都当成嵌套，事件下又重复整串动作；条件区固定写“无前置条件”。
- 传统视图参数通过居中模态窗口编辑，与“标量就地、复杂值邻近选择”的定稿不符。
- 无事件的触发器被当成不执行，与代码生成（`InitTrig` 中 `TriggerExecute`）不一致。

## 行为

- **结构**：事件 / 条件 / 动作三段；顺序动作同级，流程节点的非后续执行端口展开为“成立 - 动作 / 不成立 - 动作”子块。共享后续（多条连线汇入）只显示“接续”引用行并锁定重排；有事件时无前驱的动作单列为“未连接的动作（不会执行）”。
- **语句**：`类别 - 句子`，参数嵌在句中。数字/文本点击原位输入，Enter 或失焦提交、Esc 放弃、非法数字不落盘；布尔点击切换；对象、区域、玩家等在参数下方打开非模态取值面板，旁边的来源按钮可改为变量/函数。已设值蓝色，缺值/未解析红色波浪线，数据连线提供的参数显示来源且只读。
- **行操作**：右键菜单（之后添加、添加到子块、上移/下移、启用/禁用、复制/粘贴、在蓝图中定位、删除）；键盘 ↑↓ 选择、Alt+↑↓ 重排、←→ 折叠、Delete、Ctrl+C/V、Enter 编辑首个参数；拖放可同块重排或跨分支移动，禁止移入自身子块。删除会桥接前后执行连线，流程节点连同子块删除。工具栏“添加”在所选行之后插入，菜单只列可执行语句。
- **条件**：整数/实数/布尔/字符串/单位类型/玩家比较与 And/Or 组，可嵌套、重排、禁用。比较运算按类型限制（对象与玩家只允许等于/不等于）。生成 `Conditions_*` 与 `TriggerAddCondition`；无事件时改用 `ConditionalTriggerExecute`；Lua 使用 `~=`。蓝图画布左上显示“N 项触发条件”，点击回到传统视图。
- **取值面板**：固定值加入“预设”（玩家 1–12 与中立、默认建筑朝向）；变量页无匹配时显示“没有该类型的变量”，可就地“新建并使用”，新变量与绑定作为同一次修改、一次撤销。函数参数内新建的变量随函数绑定一并提交。
- **浮层**：`AnchoredPopover` 由蓝图与传统视图共用（蓝图贴节点右侧，语句贴参数下方，空间不足翻转）。首次定位在布局阶段同步完成并聚焦首个输入框，修复了此前需等下一帧才可见、打开瞬间无法聚焦的问题。

## 结构

- `ecaModel.ts`：从同一张图推导 ECA 块；`setChain`/`insertNode`/`removeItems`/`moveItem` 只改写执行连线，数据连线不变；条件类型、语句模板与参数显示。
- `TraditionalView.tsx`、`traditional.css`：传统视图、语句参数、行操作、条件编辑。
- `AnchoredPopover.tsx`、`parameterFields.ts`：共用浮层与参数元数据（从 `NodeParameterField.tsx` 抽出）。
- `TriggerWorkspace.tsx`：移除旧 `TraditionalTree` 与模态 `ParameterDialog`；插入请求、条件入口与新节点避让。
- `triggerCode.ts`：触发条件生成。`sample.ts`：读取时校验条件结构，无效即拒绝导入。

定义可自带 `category` 与 `sentence`（`{字段或输入端口 id}` 占位）；内置 `core.*` 在 `ecaModel.ts` 补齐，其余回退为“标题：参数…”。
