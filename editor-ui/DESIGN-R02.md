# R02 工作台设计

已沿用用户确认的 R01 视觉与模块研究方案，无须重新选择方向。本轮只开发前端交互原型。

- 视觉：石墨灰工作区、低对比薄边线、青绿色选中与操作；事件、布尔、数值端口只使用少量语义色。
- 字体：Segoe UI / Microsoft YaHei UI；代码 Cascadia Code / Consolas。以 13px 工作区文字、12px 表格辅助文字和 18px 文档标题形成层次。
- 内容：直接打开触发器示例；模块侧栏、当前文档、主体编辑区、按需属性面板和底部状态。没有介绍页或营销卡片。
- 间距：4px 基数；行高 30–36px；控件圆角 4–6px，节点 8px；弹层有轻阴影，普通面板无装饰阴影。
- 动效：120ms 焦点和选中反馈、140ms 弹层进入、拖动节点与连线即时跟随；遵循减少动画偏好。
- 主题：继承石墨、深海、浅色三种方案；布局密度和辅助面板可调。
- 数据：明确的示例工程；本地保存与 JSON 导出是真实功能，原生地图、编译器和 C++ Core 不冒充接通。
- 并行边界：共享类型与样例由主代理维护；触发器、物编/变量、声音/资源分别由独立代理负责；主代理集成主工作台、战役、AI、物体管理和世界概览。
