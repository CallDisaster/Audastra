# R06 · 真实原版数据与高密度物编

预览：`npm --prefix editor-ui run dev -- --host 127.0.0.1 --port 5178`，进入“物体”。需要先导出本机原版数据（见下）；没有数据时自动回退到 R05 的示例物编，并在顶部提示导入方法。

## 本机原版数据

```bash
node editor-ui/tools/import-war3-data.mjs --game "<魔兽争霸 III 安装目录>"
```

- 通过 `build/vs2026/src/Cli/Release/war3-map-cli.exe` 的 `game-extract` 与 `blp-decode` 从本机经典版 MPQ 读取 63 个文件：七类 SLK 与 MetaData、各种族 profile、`WorldEditStrings`、`UnitEditorData`、`WorldEditData`。按钮图标由 BLP 转为 PNG（本机 950 个，0 失败，约 35 秒）。
- 输出到 `editor-ui/public/local-data/war3/`（`index.json` 为字段元数据、枚举、物体摘要；`values-<类别>.json` 为各物体字段值，打开对应类别时再加载）。原始文件缓存在 `editor-ui/local-data/`。两个目录都已加入 `editor-ui/.gitignore`，构建时 `vite.config.ts` 也会删除 `dist/local-data`。**这些是暴雪数据，禁止提交或分发。**
- 本机导出结果：单位 836、物品 273、技能 799、魔法效果 237、科技 89、可破坏物 247、装饰物 469；字段元数据按原版 useUnit/useHero/useBuilding/useItem 与技能 useSpecific 过滤。本机汉化把 art 类别译成“技能”，与 YDWE 中实际显示的“显示”不符，导出时已修正。

## 物编

- **布局**：七类标签 → 左侧按原版分组的目录（种族 / 近战·战役 / 单位·建筑·英雄·特殊；技能按种族与单位/英雄/物品；物品按分类；装饰物与可破坏物按类别），24–26px 行，带真实图标 → 高密度字段表 → 按需右侧抽屉。1080p 一屏约 29 个字段（R05 约 8 个）。
- **数据语义**：原版目录只读；地图只保存覆盖（`EditorObject.base` + `values`，等级字段为数组）。改回基础值时自动撤销覆盖，未修改的原版物体不留空记录；自定义物体同样只存差异。
- **字段表**：按原版类别分组、可折叠、显示修改数。数值/文本就地编辑（按元数据校验最小值、最大值、整数和非负），布尔是勾选框，单选枚举是下拉框。等级字段在同一行按等级并排编辑，超过 6 级时其余等级在抽屉中编辑。修改过的行左侧有强调色，可一键恢复基础值。支持按字段名/ID/值搜索、只看已修改、显示原始字段 ID 与原始值。
- **抽屉**：物体引用列表（技能、英雄技能、单位、物品、科技、魔法效果、需求）以“已选有序列表 + 可搜索候选”同面板编辑，可上下移、移除，未知 ID 标红并保留；英雄技能栏只列英雄技能。标志集合（目标允许、路径类型、地形设置等）用多选。长文本与多等级提示带原版颜色代码预览，并把 `<AHbz,DataA2>` 这类占位符按对应等级数值显示（原版编辑器只显示原文）。
- **操作**：复制为自定义（ID 按原版规则：单位沿用基础首字母，其余 A/B/I/R/D 前缀，后三位递增并避开已有 ID），恢复原版/清除修改，删除自定义物体（可撤销）。旧工程中没有基础物体的自定义物体可“选择基础物体”迁移，已有修改保留。表头“静态引用 N”列出触发器、条件、其他物体字段、AI、放置实例中的直接引用，并注明不含脚本与动态引用、不能作为安全删除依据。
- **键盘**：目录 ↑↓ 选择，Enter/→ 进入字段表；字段表 ↑↓ 移动、Enter 编辑、Enter 提交后焦点留在表格、Esc 放弃、Delete 恢复基础值；Ctrl+Z 撤销一次只撤一步。
- 选中项被撤销或删除时回到上一个仍存在的物体，而不是跳到列表开头；复制后自动清空目录搜索并定位到新物体。

## 跨模块

- `objectCatalog.ts`：地图物体优先、原版目录其次的统一查找。触发器取值面板的单位/技能等固定值列出原版物体（每次最多显示 240 个，靠搜索和种族/分类筛选），句子显示、代码生成与图标都能识别原版 rawcode。
- 全局搜索（Ctrl+K）输入两个字符以上时包含原版物体；精确的名称或 rawcode 排在最前，选中后直接打开物编对应条目。
- 引用统计补上了触发条件与 If 条件、物编列表字段中的逗号分隔 rawcode。变量页的引用数、引用列表以及“替换后删除/改名”都会处理条件中的变量绑定。此前只在条件中使用的变量显示 0 个引用，删除时没有提醒，条件中会留下悬空绑定。
- 窄窗口（≤1000px）下触发器属性区可通过工具栏按钮以抽屉形式打开。
- 传统触发器视图：点参数会同时选中所在行；回车提交后焦点回到语句树，可继续用方向键。

## 未完成

- 多选批量编辑（只改共同适用字段、混合值状态）尚未实现。
- 模型、图标、声音路径仍是文本输入，还没有资源选择器和模型预览（模型预览计划由原生端 D3D11 插件提供）。
- 可破坏物/装饰物没有按钮图标，目前显示空白占位；原版用模型预览区分。
- 数据只覆盖经典版（1.27 布局）；导入脚本按 C++ `StandardObjectCatalog` 的默认文件清单读取，其他版本需要调整来源列表。
- 触发条件行仍不能复制粘贴；多事件共享动作的模型差异见最终方案 7.1。
