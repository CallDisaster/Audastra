# R08 · 世界页三件套、命令面板、本次修改、测试与助手

预览：`npm --prefix editor-ui run dev -- --host 127.0.0.1 --port 5178`，打开后按 `Alt 9` 进入世界页。原版图标与目录沿用 README-R06 的本机数据导入，缺失时回退到示例物体。

R08 在 R07c 的外壳（顶栏模块切换、右侧停靠、浮动窗口）上补齐现代编辑器常见、而原版 WE 缺少的几块。视觉仍用 R03 石墨令牌，用词沿用 WE。原型只证明布局与交互，数据与保存仍由原生端的共用服务负责。

## 1. 世界页：大纲 | 视口 + 资源浏览器 | 属性

| 区域 | 做什么 | 关键交互 |
|---|---|---|
| 场景大纲 `WorldOutliner` | 列出地图上全部单位、物品、可破坏物、装饰物、区域、镜头；单位按所属玩家分组 | 搜索名称/rawcode，按类别筛选；单击选择、Ctrl 切换、Shift 连选；双击对准；每行眼睛（隐藏）和锁（不可点选）；整组全选/隐藏；↑↓ 键移动 |
| 视口 `WorldViewport` | 原型为二维俯视示意；原生端是 D3D11 实际画面，交互相同 | 见下表 |
| 资源浏览器 `AssetBrowser` | 可摆放物体：地图物体在前，原版目录在后；另有“地图文件”页 | 类别页签、来源与分组筛选、缩略图/列表；单击进入摆放，拖进视口放到指定点，双击打开物体定义；高度可拖动，可收起 |
| 属性 `WorldInspector` | 单选显示完整属性；多选时相同值直接显示，不同值显示“多个值”，改一次写入全部所选 | 所属玩家、X/Y、朝向、缩放、生命/魔法百分比、英雄等级；区域名/范围/颜色；镜头位置/距离/视野/旋转/俯仰；对齐到网格、副本、删除；被引用列表 |

视口操作：

| 操作 | 方式 |
|---|---|
| 工具 | `V` 选择 · `B` 摆放 · `R` 区域 · `C` 镜头；`Esc` 回到选择 / 取消选择 |
| 选择 | 单击；`Shift` 加选；`Ctrl` 单击取消；拖空白处框选（`Shift` 追加）；`Ctrl A` 全选 |
| 移动 | 拖动已选对象，按吸附步长对齐；方向键微调（`Shift` ×4） |
| 转向 | `Ctrl` 拖动已选对象，朝向指向鼠标，按角度步长吸附（原版行为） |
| 复制 | `Ctrl C` / `Ctrl V` 粘贴到光标处并保持相对位置；`Ctrl D` 就地副本 |
| 视图 | 中键/右键/`Alt` 拖动平移；滚轮以光标为中心缩放；`F` 对准选择；`Home` 全图；书签保存视图，也可以跳到地图镜头 |
| 摆放 | 半透明预览跟随光标（已吸附）；可选所属玩家；连续单击连续摆放 |
| 区域 | 拖出矩形；选中后四角调整大小；区域内部不拦截点击，框选区域里的单位时不会选中区域 |
| 显示层 | 网格、区域、镜头、装饰物、单位名称；通行图显示留给原生端 |

大纲和属性可以从视口工具条两端收起，给视口让出空间。工具条在宽度不足时只显示图标。

高度字段显示为“随地形 · 只读”。原版会重算复制对象的高度，规则还在取证（H1），证实之前不开放手工修改。

## 2. 命令面板（`Ctrl K` / `Ctrl P`，只搜命令用 `Ctrl Shift P` 或输入 `>`）

- 一个输入框同时搜命令和工程内容：触发器、物体、变量、声音、导入文件、地图对象；输入两个字以上时加入原版物体。
- 排序规则在 `commandRank.ts`：精确匹配优先，其次开头匹配、包含、子序列；多个词必须全部命中；最近用过的命令靠前。
- 命令表与顶栏按钮、快捷键共用同一套定义，包括保存、撤销、返回、打开各模块、审阅修改、测试、助手、世界工具、吸附、网格、对准、选择同类、工程与设置。原生端的命令注册表也供 Agent 使用。

## 3. 右侧工具面板：修改 / 测试 / 助手

三者都是全局工具，不进模块切换器。打开时占用主区右侧一列，把内容推开而不是盖住，宽度可以拖动。顶栏有入口：“修改”按钮上显示未保存修改的数量，“测试”可按 `F5`，助手是一个图标。

### 修改（`projectDiff.ts` + `ChangesPanel`）

- 与上次保存的工程比较；从没保存过的工程以打开时的内容为基线。
- 按模块分组，列出新增、删除、修改，以及每个字段的前后值。
- 每一项可以“转到”，也可以单独撤销；撤销本身也记入撤销历史。另有“全部撤销”和“保存 N 项”。
- 触发器的变化汇总为节点、连线、条件各新增、删除、修改几处。
- 助手应用的改动带“助手”标记。
- 原生端在这里按地图成员列出将写出的文件（w3u、wtg、w3r…）和脚本重建结果。门禁拒绝的项目要标出原因，不能静默跳过。

### 测试（`TestRunPanel`）

- 流程是：检查工程 → 生成地图脚本 → 另存测试副本 → 启动游戏。任何一步失败就停下，列出可点击的问题。
- 原型实际执行前两步（结构检查、JASS/vJass/Lua 生成）。后两步显示“未连接后端”并说明原生端怎么做，不假报成功。
- 选项：游戏（经典 1.27a / YDWE 测试入口）、测试玩家、窗口模式、保留测试副本。测试副本写到工程的测试目录，原图不动。

### 助手（`assistantIntents.ts` + `AssistantPanel`）

- 流程是：自然语言 → 编辑命令 → 带差异预览的提议 → 作者点“应用”后作为一次撤销步骤写入。查询和选择不改数据。
- 提议绑定生成时的工程修订号。之后工程只要有变化，提议就标为过期，必须重新生成。
- 每条回复下可以展开“命令”，看到对应的调用，例如 `world.setOwner(ids, owner, baseRevision)`。这也是原生 Agent 接口的形状。
- 原型只识别六类句式：未使用变量、某对象的引用、选中所有某物体、把选中的单位改为玩家 N、把某物体的某字段改为/增加/减少 N、在某区域放置 N 个某物体。其他句子如实回复不支持，不去猜。
- 界面上注明“本地句式解析，未接语言模型”。

## 4. 原生端（Qt）对应与后端需要补的接口

| 原型 | Qt 模块 / 服务 | 需要的后端能力 |
|---|---|---|
| `worldStore`（选择集、工具、吸附、隐藏/锁定、书签） | `QtModules/World` 的 `WorldViewState` + 共用 `SelectionService` | 选择集用稳定实例 ID；UI 与 Agent 共用；不进撤销历史，也不写进地图 |
| `worldModel`（移动、复制、删除、批量改） | 现有 `PlacementEditing` 事务 | 多对象一次事务、一次撤销；复制保留属性并分配新的创建编号；区域/镜头与实例同一套操作 |
| 视口 | D3D11 渲染插件 + 拾取缓冲 | 最小屏幕半径拾取；框选按实例中心；Ctrl 拖动转向；摆放幽灵预览（已有 H1 半透明模型） |
| 场景大纲 | 新 `WorldOutliner` 控件（`QTreeView` + 模型） | 有界分页查询实例/区域/镜头；按玩家分组；增量刷新 |
| 属性（多值） | `QtUiKit` 通用属性表单 | 字段目录 `MapFields` 提供可写范围；多选混合值；写入走同一编辑门禁 |
| 资源浏览器 | `QtModules/World` 底部停靠页 | 物体目录分组；模型缩略图由离屏渲染生成并缓存（按资源层修订失效） |
| 命令面板 | `QtShell` 的 `CommandPalette` + `CommandRegistry` | 命令有 ID、标题、分组、快捷键、可用状态；Agent 用同一注册表 |
| 修改面板 | 右侧停靠组固定页 + `MapSaveService` 预检 | 按成员、记录、字段列出差异；逐项撤销生成反向编辑；列出门禁拒绝原因 |
| 测试面板 | 新 `TestRunService` | 候选副本写到测试目录、重开校验、按客户端启动游戏、回收退出码；绝不覆盖原图 |
| 助手 | MCP/Agent 适配器 + 提议队列 | 提议 = 带 `baseRevision` 的编辑批次；修订变化即过期；应用走普通事务 |

建议的实现顺序：命令注册表与命令面板 → 修改面板（先接地图数据字段和放置实例）→ 世界页大纲与多选属性 → 资源浏览器与缩略图 → 测试服务 → 助手提议队列。

## 5. 数据兼容

- `world.space = 'world'` 表示使用世界坐标（x 向东、y 向北，1 格 = 128）。R07 及以前的 0–100 俯视比例在读取时自动换算，区域从左上角改为左下角。
- 新增的可选字段：实例的 `z`、`scale`、`life`、`mana`、`level`；区域的 `color`；`world.bounds`、`world.cameras`。旧工程可以直接读取。
- 示例世界是 64×64 地图，里面有玩家单位与建筑、中立敌对、物品、装饰物、树、城门、三个区域和两个镜头。原版 rawcode（htow、hbar、ngno…）在有本机数据时显示真实名称和图标。
