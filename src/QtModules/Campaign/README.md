# 战役编辑

在“文件 → 打开”中选择 `.w3n`，或把战役文件拖进 Audastra。顶栏的“战役”模块分为章节、菜单、共享数据、资源、设置五页。

- **章节**管理战役中实际存放的地图，可以添加、替换、移除、调整顺序或导出。
- **菜单**管理战役选择画面的按钮。一个地图可以有多个按钮，也可以没有按钮；按钮有独立的标题、目标地图和初始可见状态。移除仍被按钮引用的地图前，先修改或移除这些按钮。脚本中的动态切图关系需要另外核对。
- **共享数据**复用物体编辑器，写入 `war3campaign.w3u/w3t/w3a/w3b/w3d/w3q/w3h`。它使用战役的字符串表，不会改当前章节的物编文件。
- **资源**复用资源管理器。未选自定义路径时，导入到 `war3campaignImported`。资源和共享物编草稿可用“应用共享修改”合入同一战役撤销记录；保存时也会提交草稿。
- **设置**编辑名称、难度、作者、说明、背景、缩略图、环境声音、雾与光标。原文件中没有可靠语义的字段保留原始值。雾颜色以原始四字节显示，不猜测颜色通道次序。

活动模块为战役时，`Ctrl+S` 保存 `.w3n`；首次保存需要选择新路径。“另存为”写到尚不存在的文件。原地保存沿用编辑器设置中的备份目录与保留数量，默认保存到本地用户数据目录中的 `Audastra/backups`。战役编辑支持撤销、重做，成功保存后仍可撤销。来源在外部变化或修订失效时会拒绝写入。

“打开章节”会打开一份由编辑器管理的临时副本。请先在地图模块保存该副本，再回到战役页点击“更新已打开章节”，最后保存战役。未完成更新时，战役保存会停止并提示；关闭或更换战役时也会提醒。临时章节需要独立长期保留时，请使用“导出”或地图的“另存为”。

地图 `.forge` 工程和自动恢复点不包含战役会话；活动战役时禁用地图工程保存入口。请把战役保存为 `.w3n` 后退出。共享数据页面中的本地草稿先应用，再撤销战役事务；也可以先放弃草稿。

MCP 提供 `open_campaign`、`create_campaign`、`query_campaign`、`query_campaign_objects`、`edit_campaign`、`undo_campaign`、`redo_campaign`、`save_campaign`、`export_campaign_member`。编辑、撤销、重做与保存都需要最近查询返回的 `document` 和 `revision` 字符串。查询按页返回，正文被截断时会标记；可按 `next_offset` 继续。界面有尚未应用的草稿时，外部写入会拒绝，避免覆盖本地编辑。共享物编字段通过精确字段身份修改；导入整类物编仍经过原生 codec 检查。

当前格式范围是经典 `war3campaign.w3f` v1。容器使用共同的 MPQ 保存与回读检查，现有解压总预算为 512 MiB；单次共享数据/资源提交为 64 MiB。匿名成员沿用无损追加保存；需要改外层战役名称或标志、删除成员时，若匿名成员使安全改写不能成立，会说明原因并拒绝。未知版本、未知文件头布局或将被覆盖的未知头部数据也会拒绝保存。

原生文件读写和结构检查不能证明游戏流程已经通过。交付战役前，请用副本在经典 World Editor 中重新打开并保存，再在 Warcraft III 1.27a 检查战役选择画面的标题、按钮可见性、共享对象和资源，并实际进入各章节、完成章节切换。跨图关系图、gamecache 状态编辑和战役专用测试配置尚未提供。
